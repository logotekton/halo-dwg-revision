## 레이어 가시성 API (계약, R1-08이 그대로 쓴다)
```ts
// packages/cad-core/src/host/cad-host.ts
interface LayerDto { name: string; color: number; visible: boolean; frozen: boolean }
layers(): LayerDto[]
setLayerVisible(name: string, visible: boolean): boolean     // 없는 레이어면 false
setLayersVisible(entries: Record<string, boolean>): void      // 한 번의 리렌더
zoomTo(box: { minX: number; minY: number; maxX: number; maxY: number }, marginRatio?: number): void
pick(worldPt: { x: number; y: number }, hitRadiusPx?: number): string[]   // 핸들 목록
on('selectionChanged', (handles: string[]) => void): () => void
on('renderIdle', () => void): () => void
```
```ts
// apps/web/src/features/viewer/host.ts (렌더러 전용 래퍼)
export async function openBytes(fileId: string, name: string, bytes: ArrayBuffer): Promise<void>
export function setLayersVisible(entries: Record<string, boolean>): void
export function layers(): LayerDto[]
export function zoomTo(box: Box, marginRatio?: number): void
export function onSelection(cb: (handles: string[]) => void): () => void
export function whenRenderIdle(): Promise<void>
export function screenToWorld(p: { x: number; y: number }): { x: number; y: number }
```

## Constraints
- 버전 핀 유지(`three@0.172.0`, mlightcad 1.6.3/1.14.3). 새 의존성 금지.
- GPL 경계, ODA 금지, i18n 키만(`viewer.*`), `contextIsolation: true`.
- 실도면 e2e `zz-real.spec.ts`는 `HALO_E2E_REAL=1`일 때만 돌고 아니면 `test.skip`. `samples/`가 없어도 verify가 녹색이어야 한다.
- 헤드리스 CI(macos-14, windows-latest)에서 뷰어 e2e가 돌 수 있어야 한다. WebGL이 없으면 `test.skip(사유)`이 아니라 **소프트웨어 렌더링 플래그**(`--use-gl=swiftshader` 등)를 `launchHalo()`에 넣어 통과시킨다. 정말 불가능하면 Decisions에 근거를 적고 skip으로 둔다.
- 힙 누수 테스트(20파일 순차 열기/닫기 <10%)는 W3-02 브리프 그대로. 시간이 없으면 5파일로 줄이고 Decisions에 적는다.
- 명령마다 `perl -e 'alarm 900; exec @ARGV' -- <cmd>`처럼 시간제한을 건다(macOS에 GNU timeout 없음).
