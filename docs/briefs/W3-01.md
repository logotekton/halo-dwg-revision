# W3-01 React 셸 + 상태 + i18n

- Owner model: Sonnet
- Size: 1.5 d
- Branch: `task/W3-01`
- Wave: 3a  Phase: P1

## Context
`apps/web`은 헤더·빈 캔버스·상태바뿐이다. P1 워크스테이션의 UI 뼈대(메뉴, MDI 탭, 좌/우 도크, 명령줄+상태바), Zustand 스토어, i18n 키 체계, 테스트 훅 확장을 만든다. 뷰어 캔버스 자체는 W3-02가 `#viewer-root`에 마운트한다. 먼저 읽을 것: `CLAUDE.md`, `docs/contracts/wave-3.md`, `docs/contracts/wave-2.md`, `apps/web/src/**`, `apps/desktop/src/preload/**`, `docs/PLAN.md` §7 편집 목록.

## Goal
탭을 열고 전환하고 닫을 수 있는 셸이 있고, 좌 도크(레이어·시트 자리), 우 도크(속성·교차검증 자리), 하단 명령줄과 상태바가 배치되며, 모든 문자열이 `ko.json` 키에서 온다. 파일 열기 버튼은 preload `files.pickDrawings()`를 호출해 경로를 `documents` 스토어에 넣는다(실제 임포트는 W3-02/W3-03 병합 후 연결).

## Files you own
```
apps/web/src/app/**              # 레이아웃, 라우팅 없음(단일 창), 단축키 맵
apps/web/src/state/**            # zustand: workspace, documents, selection, viewer
apps/web/src/components/**       # Header, TabStrip, LeftDock, RightDock, CommandLine, StatusBar(기존 수정)
apps/web/src/i18n/ko.json        # 접두 app/menu/files/tabs/viewer/crosscheck (계약)
apps/web/src/test-hooks.ts       # getDocuments 추가(openFiles는 W3-02/03 후)
apps/web/src/features/files/**   # 열기 버튼·최근 파일 목록(로컬 상태만)
apps/desktop/src/preload/**      # files.pickDrawings 노출
apps/desktop/src/main/ipc.ts     # halocad:files:pick-drawings 핸들러(dialog.showOpenDialog, DWG/DXF 필터)
```

## Forbidden
`packages/**`, `engine/**`, `apps/desktop/src/main/engine/**`, `apps/desktop/src/main/index.ts`(패치 제안), 루트 설정.

## Constraints
- Zustand 5, Tailwind 4 + shadcn/ui(Radix) 도입 허용(MIT). 신규 의존성은 보고서에 나열.
- 레이아웃: 헤더(제품명·메뉴), 탭 스트립, 본문 3열(좌 도크 260px 접힘 가능 / 중앙 `#viewer-root` / 우 도크 320px 접힘 가능), 하단 명령줄(입력만, 실행은 W3-02 연결), 상태바(엔진 상태 유지 + 좌표·단위 자리).
- 단축키: `Cmd/Ctrl+O` 열기, `Cmd/Ctrl+W` 탭 닫기, `Ctrl+Tab` 탭 전환.
- 모든 문자열 i18n 키(린트가 강제). 메뉴 항목은 실제 동작이 없어도 키만 등록하지 말고, 동작 없는 항목은 비활성으로 표시.
- 테스트: vitest 컴포넌트 테스트(탭 열기/닫기, 도크 접기, 단축키), 스토어 단위 테스트. e2e `tests/e2e/shell.spec.ts` 추가(`packages/testing` 헬퍼 사용): 탭 두 개 열고 전환·닫기.
- `pickDrawings`는 e2e에서 다이얼로그를 띄우지 않도록 `HALO_E2E=1`일 때 환경변수 `HALO_E2E_PICK_FILES`(쉼표 구분 경로)를 대신 반환.

- 테마는 다크 고정(배경 토글은 W3-04).
