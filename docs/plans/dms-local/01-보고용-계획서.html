변경 전·후 도면 비교·표기 도구 구축 계획

설계사에서 변경 도면 세트가 오면, DWG 파일을 열지 않고 두 세트를 넣는 것만으로 어느 도곽(도면)의 무엇이 바뀌었는지를 겹쳐 보기와 클라우드 마크 도면, 변경 리스트로 확인하고 배포한다.

1지금의 문제

변경 도면이 오면 어느 시트가 바뀌었는지 사람이 한 장씩 겹쳐 봐야 한다. 한 파일에 도곽이 수십 개 들어 있는 경우도 있어 더 어렵다. 놓친 변경은 시공 오류와 재작업으로 이어진다.

실제 실시도서 세트 68장을 분석한 결과, 비교 도구가 어떻게 생겨야 하는지는 이미 정해졌다.

확인된 사실의미
68장 전부 모델공간 하나에 도곽이 여러 개. 표제란 블록 수가 공종별 PDF 페이지 수와 정확히 일치비교 단위는 파일이 아니라 도곽이다
표제란의 도면번호·도면명·축척·날짜가 블록 속성으로 들어 있고 프로그램이 전부 읽어냄OCR이 필요 없다. 스캔본이 아니면 글자를 직접 읽는다

2제안

두 가지 사용 방식

방식내용장점단점순서
외부 앱 1차CAD를 열지 않는다. 변경 전·후 폴더를 지정하면 도곽을 맞추고 비교해 클라우드 마크와 변경 리스트를 만든다사용성이 가장 좋다. CAD 좌석이 없어도 된다. 이미 만든 엔진과 뷰어를 그대로 쓴다CAD 안에서 바로 그리는 편의는 없다먼저
ZWCAD 애드인 2차ZWCAD 안에서 "이전 리비전과 비교" 명령 한 번으로 같은 엔진의 결과를 도면 위에 표시CAD 사용자에게 편하다ZWCAD 버전에 묶인다나중에 얇게

두 방식은 경쟁 관계가 아니다. 같은 비교 엔진의 두 입구다. 외부 앱을 먼저 완성하면 애드인은 결과를 불러오는 명령 하나로 끝난다.

동작 흐름

산출물 세 가지

겹쳐 보기와 마크업 DWG는 같은 무게다. 변경 리스트는 종이나 PDF가 아니라 앱 안에서 바로 보고 고치고 승인하는 목록이다. 검토는 도곽별로 하고 출력은 전체 도곽 또는 선택 도곽 단위로 한다.

겹쳐 보기 앱 화면

변경 전은 회색, 후는 청록으로 겹치고 변경 영역에 번호를 붙인다. 번호를 누르면 그 자리로 확대된다.

마크업 DWG 파생 파일

변경된 도곽마다 변경 후 도면 사본에 별도 레이어로 클라우드 마크·번호를 넣고 그 도곽의 리비전 표를 삽입한다. 전체 도곽을 한 번에 만들고 원본은 그대로 둔다.

변경 리스트 앱 안

항목을 고치고 승인·무시를 정하면 도곽별 리비전 표와 전체 변경 리스트(도곽별 묶음) 두 가지로 나간다. 도면에 넣거나 표 텍스트로 복사해 CAD·엑셀에 붙인다.

무엇을 "변경"으로 보는가

3화면 구상

화면은 네 장이다. 세트 지정 → 도곽 목록 → 비교 작업 → 출력 순서로 이어지고, 시간은 대부분 세 번째 화면에서 쓴다. 출력 범위는 전체 도곽이 기본이고 선택 도곽도 된다. 그림은 배치와 동작을 잡기 위한 초안이라 세부 모양은 개발하면서 바뀐다.

화면 A · 세트 지정

화면 B · 도곽 목록

화면 C · 비교 작업 화면

화면 D · 출력

도곽 선택 대화상자. 출력 범위를 선택 도곽으로 고르면 변경된 도곽의 목록이 대화상자로 뜬다. 도면번호·도면명·승인 건수가 체크 목록으로 나오고 전체 선택·해제와 검색이 있다. 체크한 도곽만 마크업 DWG와 변경 리스트로 나간다. 이 대화상자는 화면 예시에서 생략한다.

4매뉴얼

  1. 변경 도면 세트를 받는다. 앱에 변경 전 폴더와 변경 후 폴더를 지정한다. XR 폴더가 같이 있으면 자동으로 읽는다. 화면 A
  2. 앱이 도곽을 뽑아 도면번호와 제목으로 짝을 맞춘다. 짝이 없는 도곽은 신규 또는 삭제된 시트로 따로 보인다. 화면 B
  3. 도곽별 변경 요약이 변경 많은 순으로 나온다. 어느 시트부터 봐야 하는지 바로 안다. 화면 B
  4. 도곽을 열면 전·후가 겹쳐 보이고 변경 영역마다 번호가 붙어 있다. 미세 이동 같은 사소한 항목은 접혀 있다. 화면 C
  5. 번호별로 승인할지 무시할지 정하고 설명을 고친다. 화면 C
  6. 도곽 검토가 끝나면 전체 도곽을 한 번에 출력한다. 변경된 도곽마다 마크업 DWG가 나오고 전체 변경 리스트가 리비전 표로 들어간다. 일부만 필요하면 선택 도곽으로 골라 출력한다. 현장과 협력사에 배포하고, ZWCAD가 있는 자리에서는 마크업 도면을 열어 확인한다. 화면 D

5왜 가능한가

근거확인된 내용
표제란을 직접 읽는다실도면 68장에서 표제란 속성 전부 추출. 표제란 수와 PDF 페이지 수가 6개 공종 모두 일치
선 단위로 비교한다픽셀 비교가 아니라 엔티티(선·치수·문자)의 식별자·기하·문자열을 비교한다. "어느 선이 얼마나 움직였는지"까지 나온다
도면 읽기가 검증돼 있다두 가지 DWG 리더가 실도면 59/68장에서 완전히 같은 결과. 한글 텍스트 20,435개에서 깨짐 0건
부품이 이미 있다파일 인입·정본화, 통계와 3중 교차검증, XREF 해석(115/115), 한글 렌더가 확인된 브라우저 뷰어, 앱 셸과 엔진 연결
원본은 손대지 않는다원본은 읽기 전용 사본으로 보관하고 마크업은 항상 새 파일에 쓴다. 코드가 원본 경로 쓰기를 거부한다
비용이 없다무료·오픈소스 스택, 사내 전용 사용 조건과 라이선스 준수. ZWCAD는 열람·검증·COM 연동·2차 애드인에 쓴다

"도면에 바로 넣기"는 ZWCAD SDK를 확인한 결과 클립보드가 아니라 COM 연동으로 푼다. ZWCAD는 LISP·VBA·COM(ActiveX)·ZRX.NET·ZRX(C++) 다섯 가지 API와 문서를 무료로 공개하며(ZWCAD 개발 문서), COM API는 외부 프로그램이 실행 중인 ZWCAD를 직접 조작하는 용도다. 외부 앱이 이 API로 열린 도면에 클라우드 마크·번호·리비전 표를 바로 그려 넣을 수 있어 애드인 없이도 삽입이 된다. ZWCAD가 꺼져 있을 때는 표 텍스트(엑셀·ZWCAD 표에 붙여넣기)와 DXF 조각 삽입으로 대신한다. 클립보드 형식 자체는 비공개라 쓰지 않는다. 개발 전반에서 이 SDK를 적극 활용하고 2차 애드인은 ZRX.NET으로 만든다.

6단계와 확인 방법

개발은 착수 시점을 정한 뒤 시작한다. 기간은 착수 후 상대 주차다.

단계내용확인 방법기간
M1 도곽 추출·매칭파일 속 도곽 목록, 도면번호·제목으로 전·후 짝 맞춤, 신규·삭제 감지, XR 자동 해석실시도서 68장에서 도곽 전수 추출이 PDF 페이지 수와 일치. 사용자가 만든 리비전 쌍에서 짝 맞춤 100%1주
M2 비교·표기도곽별 기하·치수·텍스트 비교, 변경 영역 묶음, 사소한 변경 필터, 클라우드 마크·번호, 마크업 DWG 생성리비전 쌍에 넣어 둔 변경을 전부 검출하고 오탐은 목록에서 걸러진다. 마크업 DWG가 ZWCAD에서 열린다2주
M3 검토 화면·변경 리스트겹쳐 보기, 번호 이동, 승인·무시, 리스트 편집, 전체 도곽·선택 도곽 출력(마크업 DWG + 변경 리스트) → ZWCAD COM 연동 삽입, 표 텍스트·DXF 조각사용자 직접 시연. 승인한 항목만 도면에 들어간다2주
M4 2차 애드인ZWCAD 애드인 명령(ZRX.NET): 열린 도면에서 이전 리비전과 비교, 결과 불러오기ZWCAD에서 결과가 열리고 명령 한 번으로 비교가 뜬다1~2주

파일럿 현장은 두지 않고 담당자가 직접 검증한다. M2의 전제인 변경 전·후 리비전 쌍은 담당자가 만든다.

7리스크와 대응

리스크대응
전·후 도곽 제목이 달라 짝을 못 맞춤도면번호·위치·내용 유사도로 보조 매칭. 남는 것은 화면에서 수동으로 짝 맞춤
설계사가 도면을 새로 그려 내부 식별자가 전부 바뀜기하 지문(형상·위치)으로 대응 관계를 다시 찾는 방식이 이미 설계돼 있음
사소한 변경이 수백 건 쏟아짐이동 허용오차·크기 기준으로 접어 두고 기하·치수를 먼저 보여줌
폰트 누락으로 화면 글자가 어긋남누락 폰트를 먼저 사용자에게 알리고, 해당 폰트를 내려받아 설치하도록 안내하거나 맑은 고딕으로 대체하는 선택지를 준다. 비교 결과 자체는 폰트와 무관
설비 도서처럼 큰 파일도곽 단위로 잘라 읽고 표시
ZWCAD 버전 종속비교 로직은 외부 엔진에 두고 애드인은 얇게 유지

8필요한 것과 결정 요청

자원은 이미 확보된 Windows PC와 ZWCAD, 담당자의 검증 시간이면 된다. 소프트웨어 비용은 없다. 개발은 AI가 수행하고 담당자가 방향을 잡는다.

  1. 착수 시점. 계획서 승인 후 언제 시작할지.
  2. 클라우드 마크 규격. 레이어 이름, 색, 번호 표기 형식(예: REV-CLOUD, 빨강, 원 안 번호)과 회사 표준이 있으면 그것.
  3. 리비전 표 양식. 도곽별 표의 열 구성(번호·내용·일자·담당)과 위치(표제란 옆), 그리고 전체 변경 리스트를 넣을 자리(표지 도곽 또는 첫 도곽).
  4. "사소한 변경" 기준. 무시할 이동 허용오차(예: 1mm)와 접어 둘 항목 종류.
