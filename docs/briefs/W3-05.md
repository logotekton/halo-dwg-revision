# W3-05 폰트·인코딩 + 사용자 폰트 추가 기능

- Owner model: Sonnet
- Size: 2 d
- Branch: `task/W3-05`
- Wave: 3b  Phase: P1
- 선행: W3-02(CadHost, 자산 배치), W3-09(실도면 폰트 누락 목록)

## Context
사용자 판정: SHX 폰트를 동봉하지 않고 **사용자가 폰트 파일을 직접 추가하는 기능**을 제공한다. mlightcad는 자체 호스팅 `fonts.json`을 읽고, MTEXT는 워커 폰트 풀을 별도로 동기화해야 한다(`docs/spikes/mlightcad-api.md` B.1~B.4, `AcTrMTextRenderer.getInstance().setDefaultFonts()`, `fonts-not-found` 이벤트). 먼저 읽을 것: `CLAUDE.md`, `docs/contracts/wave-3.md`("사용자 판정 반영"), `docs/spikes/mlightcad-api.md` B, `docs/spikes/real-dwg-measurement.md`(W3-09 폰트 누락 목록), `docs/dev/cadhost-proposal.md`(setFontChain), `packages/cad-core/src/host/**`, `apps/desktop/src/main/protocol.ts`(halocad:// 자산).

## Goal
1. 기본 폰트 팩: Noto Sans KR(OFL) WOFF + mlightcad 기본 폰트 중 라이선스가 확인된 SHX(라틴 `txt.shx`/`simplex.shx` 등 공개 도메인만; 한글 빅폰트는 동봉하지 않음) → `apps/web/public/viewer/fonts/fonts.json`.
2. **폰트 추가 UI**: 설정 → 폰트 → "폰트 파일 추가"(SHX/TTF/OTF/WOFF 다중 선택) → `<userData>/fonts/`에 복사 → 사용자 `fonts.json` 병합(빅폰트 인코딩은 euc-kr 기본, 선택 가능) → 워커·메인 폰트 풀 재동기화 → 열린 문서 재렌더. 목록에서 삭제·인코딩 변경.
3. SHX 이름 매핑 표: 도면이 참조하는 SHX 이름 → 대체 폰트(추가한 SHX 또는 Noto). 영속(`<userData>/fonts/mapping.json`).
4. 누락 폰트 패널: 문서 열 때 `fonts-not-found`와 워커 측 누락을 합쳐 목록 표시, 각 항목에 "이 폰트 추가…" 버튼.
5. 인코딩 override: 파일별 코드페이지 지정 후 재개방(뷰어 미리보기 경로와 엔진 정본 모두 반영 — 엔진 API `POST /files/{id}/encoding`은 W3-03 범위 밖이면 패치 제안).

## Constraints
- 동봉 폰트는 파일마다 라이선스 근거를 `docs/dev/fonts.md`에 표로. 불확실하면 동봉하지 않는다.
- 사용자 추가 폰트는 `halocad://app/fonts-user/` 같은 별도 스킴 경로로 서빙(userData 디렉터리 매핑, 스킴 핸들러 확장은 W3-02 protocol.ts에 패치 제안 또는 IPC로 base64 로드).
- 워커 동기화가 안 되면 `useMainThreadDraw`로 폴백하고 Decisions에 기록.
- e2e: F03(빅폰트 스타일)을 기본 팩으로 열면 누락 패널에 `whgtxt.shx`가 뜨고, 테스트용 공개 SHX(라이선스 확인된 것)를 추가하면 사라지며 렌더가 바뀐다.

## 추가 요구 (2026-09-03, G1 답변)
- 대체 서체 순서: 사용자 추가 폰트 → **맑은 고딕(시스템 설치본, 동봉 금지)** → Noto Sans KR. 시스템 폰트 탐색(`/Library/Fonts`, `~/Library/Fonts`, `C:\Windows\Fonts`)으로 `malgun*.ttf`를 찾아 `halocad://app/fonts-system/`으로 서빙(복사하지 않고 스트리밍). 없으면 Noto.
- 실세트 누락 폰트 목록(`docs/spikes/real-dwg-measurement.md`)의 SHX 19종·TTF 33종에 대해 기본 매핑 표를 미리 채운다(한글 계열 → 맑은 고딕, 라틴 SHX → `txt.shx` 계열).
- 텍스트 폭 차이 경고: 대체 폰트로 그린 문자 개수를 상태바/누락 폰트 패널에 표시("대체 서체 n개 스타일").
