## Context
엔진에는 인입 모듈(정본 DXF, 통계, 교차검증)과 system 라우터만 있다. 프로젝트 번들, 임포트 잡, WS 진행률, 변환 요청 왕복을 만든다. 먼저 읽을 것: `CLAUDE.md`, `docs/contracts/wave-3.md`, `docs/PLAN.md` §3·§4, `docs/adr/0002-working-dxf.md`(개정 절), `engine/src/halo_engine/**`(특히 `ingest/working_dxf.py`, `validate/crosscheck.py`, `api/main.py`, `cli.py`), `engine/README.md`.

## Goal
`POST /projects` → `POST /projects/{id}/drawing-sets` → 잡(원본 복사·DWG 변환 요청·정본 DXF·통계·교차검증 게이트) → WS 이벤트 → `GET /drawing-sets/{id}/files` → `GET /files/{id}/working-dxf`가 동작한다. DWG 변환은 데스크톱에 WS로 요청하고 `POST /files/{id}/converted`로 받는다(데스크톱 미연결 시 acad-ts CLI 폴백을 엔진이 subprocess로 실행할 수 있게 옵션 `--converter-fallback acad-ts`).

## Constraints
- 번들 `<name>.halo/` 레이아웃은 PLAN §4 그대로. 원본 쓰기 거부 가드(테스트).
- SQLAlchemy 2 + Alembic. 테이블은 PLAN §4의 파일 계열만(시트·레벨·부재는 P3).
- 잡: `ProcessPoolExecutor(spawn, 2)`, 진행률 큐 → WS 브로드캐스트. 취소 지원.
- 변환 요청: DWG면 WS `convert.request` 후 `converted` 콜백을 최대 10분 대기. 데스크톱이 없으면(`--converter-fallback`) `node packages/acad-bridge/bin/acad-bridge.mjs dwg2dxf` 실행.
- 교차검증 게이트(ADR-0002 개정 4항): 산출 DXF 열기 실패·감사기 삭제>0·엔티티 수 ±0.5% 초과 → 변환 실패 처리(다음 후보 또는 `NEEDS_MANUAL_CONVERSION`).
- 통계·교차검증 리포트를 `drawing_file.parser_crosscheck`에 저장(뷰어 측 stats는 `POST /files/{id}/crosscheck`로 나중에 갱신).
- 테스트: httpx TestClient 통합(픽스처 F06.dxf·F10 세트 임포트 → 파일 목록·정본 DXF 스트림·통계), 잡 취소, WS 이벤트 순서, 원본 불변, `converted` 왕복(가짜 변환기).
- mypy strict 대상 패키지(`model`) 유지.
