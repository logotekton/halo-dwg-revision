## Constraints
- 레이어 조작은 mlightcad `AcApLayerService`/`AcApDocument.layerStore`를 CadHost 메서드로 래핑(`setLayerVisible/frozen/locked`, `isolateLayers`, `setLayerTempColor`, `zoomToLayer`). mlightcad 임포트는 여전히 surface 파일에서만.
- 해치·문자·선가중치 토글은 mlightcad에 직접 API가 없으면 레이어 필터/시스템 변수(`LWDISPLAY` 등)로 구현하고, 불가하면 Decisions에 기록 후 비활성.
- 실제 세트(`samples/2026-09-02-실시도서/01_건축/A-810 천장 평면도.dwg` 등)로 레이어 수백 개 성능 확인(패널 렌더 < 100ms, 가상 스크롤).
- e2e: F06 열기 → `S-COL` 끄기 → 스크린샷 diff에서 기둥 사라짐 → 격리 → 복원.
