## Context
사용자가 화면 C에서 승인한 클러스터만 `REV-<YYYYMMDD>[-n]` 레이어의 클라우드 마크·삼각 번호와 표제란 왼쪽의 리비전 표(번호·내용·일자)로 후 도면 사본에 얹어 `출력/<날짜>[-n]/`에 DWG로 낸다. DWG 저장은 배경 ZWCAD가 우선이고, 없으면 DXF로 남긴다(acad-ts 라이터는 ATTRIB 복제 결함이 있어 표제란이 든 도면에는 쓰지 않는다). 먼저 읽을 것: `CLAUDE.md`, `docs/contracts/compare-dxf.md` §1·§2(마크업 규칙)·§5·§6·§8, `docs/contracts/r1.md` §2·§3(`run`)·§6·§7·§11, `engine/src/halo_engine/compare/{cluster,compare_dxf,zwcad,config}.py`, `api/routers/compare_clusters.py`·`api/jobs.py`, `db/repos.py`(`create_run` 등), `bundle/guard.py`, `packages/acad-bridge/README.md`(dxf2dwg 한계), `engine/tests/compare/{conftest,scenario_helpers}.py`.

## Goal
1. `compare/markup.py`
   - `write_markup_dxf(after_working_dxf, clusters(approved only, 사이드카에서), frame, run_date, layer_name, config, out_path) -> MarkupResult`: 후 작업용 DXF를 통째로 읽어(도곽 밖 포함, 원본 레이어 그대로) `layer_name`(색 1) 레이어를 만들고 승인 클러스터의 클라우드 LWPOLYLINE·배지 삼각형·번호 TEXT를 **사이드카의 좌표 그대로** 넣는다(재계산 금지 — 화면과 출력이 같아야 한다). XDATA `HALO_CMP`(`cluster=`, `role=`)도 단다. `pin_header_for_determinism` 적용.
   - `draw_revision_table(doc, frame, rows, run_date, layer_name, config, scale_factor)`: `compare-dxf.md` §6. LINE + TEXT만. 행 = 승인 클러스터 번호 순, 내용 = `user_label or label`, 일자 = `run_date`. 긴 내용은 열 너비에 맞춰 잘라 `…`.
   - 승인 0건인 짝은 파일을 만들지 않는다.
2. `compare/export.py`
   - `resolve_output_dir(project_dir, run_date, config) -> (Path, layer_name)`: `<project_dir>/<output.dir_name>/<run_date>`가 없으면 그것과 `REV-<YYYYMMDD>`; 있으면 `-2`, `-3`… 같은 접미사를 레이어에도.
   - `async run_export(app, *, job, bundle, compare_set_id, run_date, scope="all", method="auto") -> Run`: `run` 행 생성(`status=running`) → 승인 클러스터가 있는 짝(전체 도곽 범위)마다 `markup.dxf`(`compare/<pair_id>/markup.dxf`) 생성 → DWG 저장: `dwg_writer`가 `auto`면 `zwcad.detect().available`일 때 ZWCAD `convert_dxf_to_dwg`(단일 스레드 executor, 인스턴스 하나), 아니면 **DXF 그대로 출력 폴더에 복사**(`writer: dxf-only`, `warnings: ["zwcad_unavailable"]`); `acad-ts`는 명시 설정일 때만. 파일 이름 `output.file_pattern`(`{sheet_no}_{after_label}_markup`, 파일명 금지 문자는 `_`). → `changes.tsv`·`run.json`(스키마 `compare/run`) → `run` 행 `done`, `compare_set.status` 복귀.
   - `write_changes_tsv(rows, path)`: 열 `도면번호	도면명	번호	종류	내용	판정	일자`, UTF-8 BOM 없음, CRLF 아님(LF). 승인·무시 모두 포함(판정 열로 구분).
   - 모든 쓰기 전 `assert_writable_path(path, allowed_roots=[bundle.root, output_dir])`.
3. 라우터 `api/routers/compare_export.py`(계약 §7): `POST /compare/sets/{id}/export {run_date, scope, method}` → 202 `{job_id, run_id}`(잡 `compare.export`, `status=compared`가 아니면 409); `GET /compare/runs/{run_id}` → `Run`; `GET /compare/runs/{run_id}/tsv` → `text/tab-separated-values; charset=utf-8`.

## Constraints
- 결정론: `markup.dxf`는 같은 입력·같은 `run_date`·같은 판정에서 바이트 동일(테스트). 출력 DWG는 ZWCAD 산출물이라 바이트 비교 대상이 아니다.
- 원본 불변: 출력·번들 밖 쓰기 금지. 테스트가 소스 폴더 해시 불변을 확인.
- 표·마크 크기는 `compare.yaml` 값 × `scale_factor`. 코드에 숫자 박지 않는다.
- TABLE 엔티티·프록시 금지. ezdxf `audit()` 오류 0.
- 잡 진행률: 짝마다 1회(`stage="markup"`/`"dwg"`), `extra={"pair_id","sheet_no","writer"}`.

## Defaults for ambiguity
- `after_label` = 후 세트 폴더 이름(`drawing_set.label`).
- 표제란 왼쪽에 공간이 없어 도곽 밖으로 나가더라도 그대로 그린다(경고 `revtable_outside_frame`).
- 무시(`ignored`) 클러스터는 TSV에만 나오고 DWG에는 안 나온다.
- 같은 날 재출력은 새 폴더(`-2`)를 만든다(덮어쓰기 금지).
- `run.json`에는 절대 경로 대신 출력 폴더 기준 상대 경로.
