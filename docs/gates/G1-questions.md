# G1 — 사용자 확인이 필요한 항목

각 항목은 제기한 태스크 id로 묶는다. 답이 오면 해당 태스크 문서에 반영하고 여기서는 지운다.

## W3-09 (실제 실시도서 세트 실측, `docs/spikes/real-dwg-measurement.md`)

1. **폰트 파일 제공과 라이선스.** 실측 결과 이 세트가 쓰는 SHX/폰트 파일 19종과 TTF 서체 33종이 뷰어 기본 폰트 세트에 **누락**이다. 사내 CAD PC에서 다음 파일을 받을 수 있는가, 그리고 사내 워크스테이션에 재배포해도 되는 라이선스인가?
   - SHX: `arcbig03.shx`(경로가 `C:\xicad\`로 박혀 있다), `ghs.shx`, `kscals.shx`, `ENGINEERING.shx`
   - TTF: 맑은 고딕(`malgun*.ttf`), 한양 `H2GTRE/H2GTRM/H2HDRM/HYWULM`, `gulim.ttc`, `Rix모던고딕 L/M`, `08서울남산체 M`, `나눔스퀘어_ac`, `HY울릉도 L/M`, `Expo M`, `HCR Dotum`, `MoeumT R`
   - 받을 수 없으면 **대체 서체로 치환**해도 되는가? (예: 한글 전부 Noto Sans KR / 본고딕으로. 글자폭이 달라져 표 안 글씨가 칸을 넘칠 수 있다.)
2. **설비 도서 6장이 현재 뷰어에서 열리지 않는다**(기계·전기·통신·소방기계·소방전기, 4.8만~34.8만 엔티티). 이 도서들이 적산 대상에 들어가는가? 보기(열람)만 필요한지, 물량 근거로 쓰는지에 따라 W3-02의 우선순위가 달라진다.
3. **`_recover` 사본 취급.** `01_건축/A-520 부분확대 상세도_recover.dwg`는 `A-520 부분확대 상세도.dwg`와 같은 2도곽을 담고 있다. 원본을 대체한 것인가, 참고 사본인가? DMS(P2)에서 이런 사본을 자동으로 어떻게 다룰지의 기준이 필요하다.
4. **적산 골든셋의 성격.** `#골조샵/*골조 수량산출서.xlsx`는 **모듈러 강구조**(H형강 기둥·보, 퍼린, 조이스트, 데크) 물량이고 콘크리트·거푸집·철근이 아니다. P4의 첫 검증 목표를 (a) 이 강구조 물량으로 바꿀 것인지, (b) 콘크리트 구조 프로젝트의 산출서를 따로 확보할 것인지.
5. **골조샵 도면의 PDF 대응본.** `#골조샵`의 12도곽에 대응하는 PDF를 찾지 못했다(`01_구조_PDF.pdf`는 31쪽이라 매칭되지 않는다). 골조샵 도면의 출력본이 따로 있는가?
6. **`docs/samples/labels.csv`의 자동 채움 허용 여부.** 이 세트는 레이아웃이 없고 도곽(표제란 INSERT)이 시트 단위다. 표제란 ATTRIB에 도면번호·축척·층이 들어 있으므로 `sheet_type`·`floor`를 자동으로 채울 수 있다. 사용자가 직접 교정하는 대신 자동 추출본을 기본값으로 써도 되는가?

## 답변 (2026-09-03, 사용자)
1. 기본값 유지하되 **대체 서체는 맑은 고딕**으로 치환. 폰트 파일은 동봉하지 않고(MS 라이선스) 시스템에 있으면 사용, 없으면 Noto Sans KR로 2차 대체. 사용자가 폰트 추가 기능으로 직접 넣을 수 있음.

6. 시트 라벨 자동 채움: 기본값 유지(자동 추출 초안 + 사용자 교정).
