## Context
DWG→DXF 변환은 배경(숨김) ZWCAD COM이 1순위다(장부). 마크업 DWG 저장(R1-09)도 같은 브리지의 `SaveAs`를 쓴다. 개발은 macOS에서 하므로 COM 호출 경계를 `ComBackend` 프로토콜로 격리하고 계약 테스트는 가짜 백엔드로 돌린다. 실제 ZWCAD 2026 Professional 확인은 사용자가 Windows 설치본으로 한다(R1-11). 먼저 읽을 것: `CLAUDE.md`, `docs/contracts/r1.md` §6.1·§7, `docs/adr/0007-zwcad-com-bridge.md`(R1-00b가 같은 날 쓴다 — 없으면 계약 §6.1로 충분), `engine/src/halo_engine/procutil.py`(프로세스 트리 종료 유틸이 있으면 재사용), `engine/src/halo_engine/api/routers/system.py`(라우터 형식), `engine/src/halo_engine/cli.py`(typer 명령 형식), `engine/tests/api/conftest.py`.

## Goal
1. `engine/src/halo_engine/compare/zwcad.py`: 계약 §6.1의 `ZwcadStatus`, `detect()`, `ConvertResult`, `ZwcadError`·`ZwcadTimeout`·`ZwcadUnavailable`, `ComBackend` 프로토콜, `ComtypesBackend`(Windows 전용, comtypes를 함수 안에서 지연 임포트), `ZwcadConverter`(컨텍스트 매니저, `convert_dwg_to_dxf`, `convert_dxf_to_dwg`, `restart`).
2. 인스턴스 규칙: `Visible=False`, 시작 직후 `FILEDIA=0`·`CMDDIA=0`·`PROXYNOTICE=0`·`FONTALT=malgun.ttf`(`SetVariable`), 열기는 `Documents.Open(path, ReadOnly=True)`, `SaveAs(out_path, <버전 상수>)`, `Close(False)`. 파일당 `timeout_s`(기본 120) 초과 시 워커 스레드에서 감시해 프로세스 트리를 죽이고 `restart()` 후 `ZwcadTimeout`. `__exit__`은 `Quit()` 후 프로세스가 살아 있으면 강제 종료.
3. `comtypes.client.gen_dir`를 `%LOCALAPPDATA%/halo/comtypes_gen`(없으면 `tempfile.gettempdir()/halo_comtypes_gen`)로 설정해 PyInstaller 설치본에서도 타입 라이브러리 캐시가 쓰기 가능하게 한다.
4. 라우터 `engine/src/halo_engine/api/routers/compare_zwcad.py`: `GET /api/v1/compare/zwcad/status` → `ZwcadStatus`. `api/main.py`에 include 한 줄.
5. CLI `halo-engine zwcad-convert <in> <out> [--timeout 120] [--dxf-version 2013]`(typer, `cli.py`에 명령 하나 추가): Windows 수동 확인용. 종료 코드 0/1과 JSON 한 줄 출력.
6. SaveAs 버전 상수 표를 모듈 상단에 문서화(`ZcSaveAsType`가 AutoCAD `AcSaveAsType`와 같은 값이라는 전제: `ac2013_dxf=61`, `ac2013_dwg=60`, `ac2018_dxf=65`, `ac2018_dwg=64`, `ac2007_dxf=37`, `ac2000_dxf=13`). 값은 상수 dict 하나에 두고 Windows 확인 뒤 고칠 수 있게 한다.

## Constraints
- comtypes 외 새 의존성 금지. pywin32 금지(ADR-0007). `import comtypes`는 `ComtypesBackend` 메서드 안에서만.
- macOS·Linux: `detect().available is False`, `reason="not_windows"`; `ZwcadConverter()` 생성 시 `ZwcadUnavailable`. 테스트는 `ComBackend`를 `FakeComBackend`로 주입해 Windows 경로를 시뮬레이션한다(`sys.platform` 몽키패치 포함).
- 시간 제한 감시는 `threading.Timer` 또는 워커 스레드 + `join(timeout)`. COM 호출은 STA 스레드 문제를 피하려고 **호출 스레드에서** 하고, 감시만 별도 스레드(감시 스레드가 `kill_process_tree(pid)`). PID는 `app.HWND`→`GetWindowThreadProcessId` 또는 프로세스 열거(`psutil` 없음 → `tasklist`/`ctypes`)로 얻는다. 얻지 못하면 `Quit()`만 하고 경고.
- 결정론과 무관하지만 로그 문구에 시각을 넣지 않는다(로거가 붙인다).
- ruff·mypy 통과. Windows 전용 API 호출은 `if sys.platform == "win32":` 안 + `# type: ignore[attr-defined]` 최소화(`ctypes.windll`은 `getattr(ctypes, "windll")`).

## Defaults for ambiguity
