# Halo CAD (halo-cad)

- 전체 계획: [docs/PLAN.md](docs/PLAN.md)
- 에이전트 규약: [CLAUDE.md](CLAUDE.md)
- 결정 기록: [docs/adr/](docs/adr/)
- 게이트: [docs/gates/](docs/gates/)
- 샘플 요청: [docs/samples/REQUEST.md](docs/samples/REQUEST.md)

## 개발 환경
Node 24 + pnpm 10(corepack), Python 3.12(uv). 자세한 명령은 `CLAUDE.md`.
