## Goal
1. 교차검증 패널(우 도크): 문서 열림 후 자동으로 `statsByLayer()` → `POST /files/{id}/crosscheck` → 레이어별 녹/황/적 표, 차이 상세, 화이트리스트 사유. 적색 레이어 클릭 → `zoomToLayer`.
2. 속성 팔레트(우 도크): 선택 객체의 일반(핸들·레이어·색·선종류)·기하(길이·면적·좌표)·문자 내용. 다중 선택 시 공통 속성. 편집은 W4.
3. 선택 기본: 클릭·창·교차 선택, 전체 선택, 선택 해제, 선택 개수 상태바.
4. 측정 기본: 거리·면적·각도 명령을 mlightcad 명령(`MEASUREDISTANCE` 등)으로 노출, 결과는 상태바와 측정 목록에. "측정"이라는 표시를 명확히(적산 아님).
