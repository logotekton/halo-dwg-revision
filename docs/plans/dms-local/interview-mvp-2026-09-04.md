# 리비전 도면 관리 앱 MVP — 인터뷰 결정 장부 (2026-09-04)

Ouroboros 소크라테스식 인터뷰(Path B, 로컬)로 확정한 내용. Seed(`ooo seed`)의 입력이며, 개발용 계획서(`02-개발용-계획서.html`)와 어긋나는 값은 이 문서가 우선한다.

## 한 줄 목표

변경 전·후 DWG 폴더 두 개를 넣으면 배경 ZWCAD로 변환해 도곽별로 짝짓고 비교한 뒤, 사용자가 화면에서 승인·무시한 변경만 REV-<날짜> 클라우드 마크와 리비전 표(번호·내용·일자)를 얹은 마크업 DWG로 내보내는 Windows 설치본을 6일(D0 선행 병합·CI 설치본 + D1~D5) 안에 기존 Halo CAD 셸·엔진 위에 만들고, verify.sh·E2E 녹색과 사용자 Windows 노트북에서 실도면 68장 도곽 수 일치, 사용자 리비전 쌍의 심은 변경 100% 검출·오탐 0으로 합격을 판정한다.

## 범위

- **Seed 범위:** 1주차 MVP만. 개발용 계획서 §7의 R1-01~R1-11에 D0 선행 작업 R1-00a·R1-00b를 더한다. 2주차(사전 기반 설명, 래스터 보조, 수동 마크·텍스트, 리비전 이력 엑셀, 선택 도곽 출력·대화상자, COM 삽입, 애드인, 라이선스 검사 스크립트)는 MVP 게이트 뒤 별도 Seed.
- **범위 밖:** 서버·계정·알림, 폴더 관리, 도곽 일괄 편집, 배포용 PDF, 물량 비교, CAD 편집, 셀프호스티드 러너, macOS 설치본, 개발 체크아웃 확인, 그룹 보기.

## 아키텍처·환경

- 셸: Electron 유지. main 프로세스는 사이드카 기동·대화상자·클립보드만.
- 실행 대상: Windows 10·11 x64. 사용자 Windows 노트북, ZWCAD 2026 Professional.
- 확인 방식: 사용자 본인이 **설치본으로만** 확인한다(개발 체크아웃 없음). GitHub Actions `windows-latest`가 task 브랜치 푸시마다 NSIS + PyInstaller x64 + comtypes 설치본을 아티팩트로 낸다(R1-00b). 사용자 PC 경로(실도면 68장·리비전 쌍)는 R1-11 시작 시 정해 `docs/gates/R1.md`에 기록.
- COM 라이브러리: comtypes(MIT). pywin32는 라이선스 허용 목록 밖. ADR-0007을 R1-02에 포함.
- 뷰어·XREF: `task/W3-06`(XREF, 검증 완료) 병합, `task/W3-02`(CadHost WIP) 검증 + 레이어 가시성 API 추가 후 병합 — R1-00a(D0).

## 비교 규칙(확정값, 계획서 §1·§4.5 기본값을 대체)

- 사소한 변경으로 접는 이동: **0.01mm 이하**. 접기 목록: 레이어·색·선종류·선굵기만 변경, 해치 재생성(경계 동일), 치수 재생성(값·문구 동일), MTEXT 서식만 변경 — 구조 규칙으로 판정하며 τ에 의존하지 않는다.
- 지문 매칭 허용오차: 1mm(이웃 구간 포함 거리 매칭). 0.01mm는 접기 판정에만 쓴다.
- 한 도곽 짝의 전·후 DXF는 같은 변환기여야 한다. 한쪽이 ZWCAD 변환에 실패하면 짝 상대도 자체 변환기로 다시 변환, 그래도 안 되면 "변환기 불일치" 표시.
- 클라우드 마크: 레이어 `REV-<YYYYMMDD>`(실행 날짜, 같은 날 두 번째 실행은 `-2`), 색 빨강(1), 호 100mm, 여백 50mm, 번호는 삼각형(한 변 200mm) 안 숫자, 도곽 축척 배율 적용.
- 리비전 표: 열 번호·내용·일자(담당 없음), 표제란 왼쪽. 일자 = 실행 날짜. 전체 변경 리스트(첫 도곽)는 2주차.
- 실행 날짜는 Run의 명시 입력(주입 시계). 결정론 테스트는 날짜를 고정.
- 비교 DXF 계약: `docs/contracts/compare-dxf.md` + 스키마(R1-01). 레이어 `__CMP_ADDED`(빨강 1)·`__CMP_REMOVED`(시안 4)·`REV-<날짜>`·`__CMP_LABEL`, XDATA appid `HALO_CMP`, 사이드카 `clusters.json`(handle → cluster_id), 전 도면 블록 이름 접두 `__B_`.
- 도곽 추출: `_recover` 파일 제외. XREF 안 표제란은 XREF 해석 후 적용. 표제란 없는 파일은 "도곽 미인식"으로 목록에 표시(수동 지정은 2주차).
- 도곽 수 합격 상수(실측, `_recover` 제외): 전기 104, 기계 51, 통신 28, 소방기계 45, 소방전기 28, 건축 99. 골조샵 12장은 PDF가 없어 추출 수만 기록.

## 완료 판정

1. `tools/verify.sh --e2e` 녹색(실제로 돌리는 검사 기준. 라이선스 검사 스크립트는 없으므로 2주차 백로그).
2. Playwright 수직 슬라이스: 세트 지정 → 도곽 목록 → 검토(승인·무시) → 전체 도곽 출력.
3. 사용자 Windows 노트북에서 설치본으로: 실도면 68장 인입 후 도곽 수가 위 상수와 일치. 사용자 리비전 쌍(`samples/revision-pairs/`, 1주 안·D4 전 제공, 심은 변경 목록 동봉)에서 심은 변경 100% 클러스터 검출, 심지 않은 곳 클러스터 0(접힌 항목 제외), 마크업 DWG가 ZWCAD 2026에서 열림.
4. 결과와 사용자 PC 경로를 `docs/gates/R1.md`에 기록.

## 작업 소유(계획서 §7 보정)

- R1-00a(D0): W3-06 병합, W3-02 검증·레이어 가시성 API·병합. R1-00b(D0, 병렬): Windows 설치본 CI(`windows-latest`, NSIS, PyInstaller x64, comtypes, `electron-builder.yml` win 타깃).
- R1-01: 스키마 5종 + 비교 DXF 계약 문서 + DB 모델·Alembic 마이그레이션. R1-04: pairs 라우터 포함. R1-06: clusters 라우터 포함, 결정론(바이트 비교) 테스트 파일 명시. R1-07: 변경 truth JSON 형식 정의(통째 사본 시나리오 포함). R1-11: 최종 설치본 + 게이트 문서(이력 엑셀 문구 삭제).
- 브리프 작성 전에 개발용 계획서 §1·§4.5·§7의 기본값·소유를 이 문서로 갱신한다.
