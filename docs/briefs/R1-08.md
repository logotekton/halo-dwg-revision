## Context
화면 C는 엔진이 만든 비교 DXF를 CadHost로 열고 사이드카 `clusters.json`을 목록으로 보여 준다. 겹쳐 보기·전·후는 레이어 가시성만 바꾸고, 번호를 누르면 카메라가 클러스터로 가며, 승인·무시·문구 편집은 `PATCH`로 서버에 저장된다. 목업은 보고용 계획서 §3 화면 C(검정 캔버스, 오른쪽 목록). 먼저 읽을 것: `CLAUDE.md`, `docs/contracts/compare-dxf.md` §2·§7·§9, `docs/contracts/r1.md` §7·§9·§10, `docs/dev/viewer-integration.md`(R1-00a), `apps/web/src/features/viewer/host.ts`, `packages/cad-core/src/host/{cad-host,types}.ts`, `apps/web/src/features/compare/{CompareApp,SheetListScreen,api}.tsx|ts`·`state/compare.ts`(R1-05), `state/viewer.ts`·`selection.ts`, `test-hooks.ts`, `docs/dev/compare-ui.md`, `packages/schema/gen/ts/compare/{clusters-sidecar,cluster}.d.ts`, `tests/e2e/{viewer,compare-sheets}.spec.ts`, `docs/plans/dms-local/01-보고용-계획서.html` §3 화면 C.

## Goal
1. `features/compare/ReviewScreen.tsx`(자리표시자 교체): 왼쪽 캔버스(`#viewer-root`, 검정 배경), 상단 도구줄(겹쳐 보기·전·후 토글, 이전/다음 도곽, 목록으로, 도곽 번호·제목·상태), 오른쪽 목록 패널(클러스터 행: 번호 배지, 종류, 문구(편집 가능), 승인·무시 버튼, 판정 칩; 하단 "접힌 항목 n건" 펼치기 목록: 사소한 변경 사유별).
2. `state/review.ts`(계약 §9): `loadPair(pairId)`(사이드카 GET → 비교 DXF 바이트 GET → `openBytes` → `whenRenderIdle` → 레이어 모드 적용), `select(number)`(목록 강조 + `zoomTo(cluster.bbox 여백)`), `decide(number, decision)`·`setLabel(number, text)`(낙관적 갱신 + PATCH, 실패 시 되돌림), `setViewMode`, `showMinor`. `features/compare/reviewApi.ts`: `getClusters`, `patchCluster`, `getCompareDxf`.
3. 배지 클릭: `onSelection(handles)` → `handle_to_cluster` → `select`. 리스트 번호 클릭 → `zoomTo`. 키보드: `A` 승인, `X` 무시, `J/K` 다음/이전 클러스터, `[`/`]` 이전/다음 도곽(ko.json에 안내 문구).
4. 보기 모드 = `setLayersVisible({__CMP_ADDED, __CMP_REMOVED, __CMP_LABEL:false, REV-*: true})`(§9). 레이어 이름은 사이드카 `layer` 값에서.
5. 이전/다음 도곽은 화면 B의 정렬·필터 순서를 따른다(`state/compare.ts`의 `pairs`).
6. 테스트 훅(계약 §10): `compareOpenPair(pairId)`, `compareGetClusters()`, `compareDecide(number, decision)`.
7. i18n `compare.review.*`.

## Constraints
- 렌더러는 판정만 보낸다. 클러스터·좌표 계산 금지. 문구 편집은 `user_label`에만.
- 비교 DXF 바이트는 짝마다 한 번만 받고 `ETag`로 캐시(같은 ETag면 재요청 안 함).
- 렌더 실패(`openFailed`)는 목록은 살려 두고 캔버스에 오류 문구.
- UI 문자열은 ko.json. 접근성: 목록 행에 `role="listitem"`, 버튼 `aria-label`.
- e2e는 소프트웨어 GL(R1-00a가 `launchHalo()`에 넣은 플래그) 위에서 돈다.
