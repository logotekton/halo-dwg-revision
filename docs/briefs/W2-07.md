# W2-07 Playwright Electron e2e 골격

- Owner model: Sonnet
- Size: 1 d
- Branch: `task/W2-07`
- Wave: 2  Phase: P0
- 선행: W1-01(main 병합). W2-01과 병행(엔진 상태 단언은 조건부)

## Context
Electron 골격이 있고 main 프로세스 스모크 훅(`HALO_E2E_SMOKE`)만 있다. 이후 모든 UI 태스크가 쓸 Playwright 기반 e2e 골격이 필요하다. 먼저 읽을 것: `CLAUDE.md`, `docs/contracts/wave-2.md`(테스트 훅), `apps/desktop/src/main/window.ts`, `docs/dev/setup.md`.

## Goal
`pnpm --filter @halo-cad/testing e2e`가 빌드된 Electron 앱을 `_electron.launch`로 띄워 창 제목 "Halo CAD"와 헤더·상태바 렌더를 확인하고 스크린샷을 남긴다. 실패 시 스크린샷·콘솔 로그가 보존된다. `tools/verify.sh --e2e`가 이를 실행한다.

## Files you own
```
packages/testing/**            # package.json(@halo-cad/testing), playwright.config.ts, src/electron.ts(launch 헬퍼), src/fixtures.ts
tests/e2e/**                   # smoke.spec.ts
apps/web/src/test-hooks.ts     # (W2-01이 만들지 않았다면) HALO_E2E 훅 최소 구현 — 충돌 시 W2-01 것을 우선하고 패치 제안
docs/dev/e2e.md
```

## Forbidden
`apps/desktop/**`(패치 제안만), `tools/**`, 루트 설정, `engine/**`.

## Constraints
- Playwright `@playwright/test`(Apache-2.0) 최신 1.5x. 브라우저 다운로드는 필요 없다(Electron 자체 사용). `npx playwright install`은 실행하지 않는다.
- 실행 전제: `pnpm build`가 끝나 `apps/desktop/out/main/index.js`와 `apps/web/dist`가 존재. 헬퍼가 없으면 명확한 한글 오류로 안내.
- `_electron.launch({ args: [mainPath], env: { ...process.env, HALO_E2E: '1' } })`. 첫 창 `firstWindow()` → `title()` === "Halo CAD".
- 단언: 헤더 텍스트, 상태바 존재. 엔진 상태 단언은 `window.__haloTest`가 존재할 때만(W2-01 병합 여부에 따라) 수행하고, 없으면 `test.skip` 사유 출력.
- 실패 시 `test-results/`에 스크린샷·비디오 없이 스크린샷만, 콘솔 메시지를 첨부.
- 스크린샷 기준선 비교(pixelmatch)는 이 태스크 범위 밖(W3 이후). 스크린샷은 아티팩트로만 저장.
- 타임아웃: 테스트 60초, 앱 기동 대기 30초.
- 스크립트: `packages/testing/package.json`에 `e2e`(playwright test), `e2e:headed`. `tools/verify.sh --e2e`는 `pnpm -r --if-present run e2e`를 호출하므로 이름을 정확히 `e2e`로.
- 헬퍼 API(`src/electron.ts`): `launchHalo(opts?) → { app, window, close() }`, `waitForStatus(window, state, timeout)`(훅 있을 때).

## Definition of done
- `pnpm build && pnpm --filter @halo-cad/testing e2e` 통과(1개 이상 테스트), 실패 재현 시 스크린샷 생성 확인(의도적으로 제목 기대값을 바꿔 1회 실패시켜 확인 후 복원).
- `tools/verify.sh --e2e` 녹색.
- `docs/dev/e2e.md`: 실행 방법, 훅 규약, 새 테스트 추가 방법.
- 커밋 `W2-07: ...` on `task/W2-07`.
