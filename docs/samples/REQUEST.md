# 샘플 도면·자료 요청 목록

실제 도면이 없으면 P0는 합성 픽스처로 진행하지만, G1(CAD)과 G3(3D 재구성)은 실제 도면 없이는 잠정 통과만 가능하다. 확보되는 대로 `samples/`(git 제외)에 넣고 아래 표를 갱신한다.

## 도면 파일

| 항목 | 목표 | 확보 | 비고 |
|---|---|---|---|
| 국내 DWG 총수 | ~100 | 0 | ≥5 설계사무소, 2008~2026, AC1021~AC1032 혼합 |
| AutoCAD에서 내보낸 DXF(2018 ASCII) 동반 파일 | ≥20 | 0 | 파서 기준 비교용 |
| XREF 기반 세트 | ≥10 세트 | 0 | 참조 파일 포함 |
| 50MB 초과 파일 | ≥5 | 0 | 대용량 실측 |
| 한글 SHX/빅폰트 사용 파일, cp949 DXF | ≥10 | 0 | |
| 구조 부재일람표 시트 | ≥15 | 0 | 기둥/보/벽/기초, 여러 사무소 |
| 층고표·레벨 표 | ≥10 | 0 | |
| 실내재료마감표·창호일람표 | ≥10 | 0 | |
| 입면도 세트(4면) | ≥5 | 0 | 해치 재료 존 포함 |
| 구조+건축 완비 프로젝트 | ≥5 | 0 | P3 3D 재구성용 |

## 적산 자료 (P4 진입 3월 초까지)

| 항목 | 목표 | 확보 |
|---|---|---|
| 준공 프로젝트 도면 세트 + 적산 담당 엑셀 산출서 + 적용 산출기준 문서 | 3~5건 | 0 |
| 사내 수량산출서 엑셀 템플릿 | 1 | 0 |
| 마감·외장 산출서(P5/P6) | 각 2건 | 0 |

## 기타

| 항목 | 확보 |
|---|---|
| 사무소에서 쓰는 SHX/TTF 폰트 파일과 라이선스 확인 | ☐ |
| 도면번호 체계, 승인 절차 문서(P2 DMS) | ☐ |
| DMS 서버 호스트 + PostgreSQL, AD/LDAP 여부(11월 초) | ☐ |
| Windows PC 유무, Windows 배포 방식 | ☐ |

## 제출 방법
`samples/<사무소코드>/<프로젝트>/` 폴더로 통째로 복사. 파일명은 바꾸지 않는다. 민감 정보가 있는 도곽 텍스트는 그대로 두어도 되며 저장소에는 올라가지 않는다.
