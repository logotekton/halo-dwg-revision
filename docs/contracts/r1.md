## 2. 저장 구조 (원본 불변)

```
<프로젝트>/
  <전 세트 폴더>/*.dwg, <후 세트 폴더>/*.dwg, XR/      # 원본. 아무도 쓰지 않는다
  .halo/                                              # 번들 (BundleLayout root)
    project.json, project.sqlite
    originals/<sha256>.dwg                            # 0444 사본. ZWCAD·자체 변환기는 이 사본만 연다
    cache/dxf/<sha256>.working.dxf                    # 작업용 DXF 정본(기존 ingest)
    compare/<pair_id>/compare.dxf, clusters.json, markup.dxf
    compare.yaml, frames.yaml                         # 첫 실행 때 기본값을 복사. 사람이 고쳐도 된다
    log/<compare_set_id>.log                          # 변환 로그, 교차검증 불일치, COM 실패
  출력/<YYYY-MM-DD>[-n]/
    <도면번호>_<후 라벨>_markup.dwg (또는 .dxf), changes.tsv, run.json
```

- 쓰기 허용 루트: 번들 루트, 출력 폴더. 모든 쓰기 전에 `bundle.guard.assert_writable_path(path, allowed_roots=[bundle.root, output_dir])`.
- `bundle.layout.BundleLayout`에 `compare_dir`(`root/compare`)·`log_dir`(`root/log`)·`compare_yaml`·`frames_yaml` 프로퍼티를 R1-01이 추가한다.
- 번들 열기: `.halo/project.json`이 있으면 `open_bundle`, 없으면 `create_bundle(path=<프로젝트>/.halo, name=<프로젝트 폴더 이름>)`. 열린 번들은 기존대로 `app.state.bundle` 하나.
- 파일 제외: `compare.yaml`의 `ingest.ignore_patterns`(기본 `["*_recover.dwg", "*.bak", "*.dwl", "*.dwl2"]`). 제외 파일은 `drawing_file` 행에 `excluded_reason`으로 남기고 변환하지 않는다.

## 3. DB (R1-01 소유, 마이그레이션 `0003_compare_records`)

`engine/src/halo_engine/db/models.py`에 추가. 컬럼 타입은 기존 규칙(SQLite 전용 타입 회피). JSON 컬럼은 `sqlalchemy.JSON`.

| 테이블 | 컬럼 |
|---|---|
| `drawing_set` (기존에 추가) | `role` String(8) null (`before`/`after`), `source_dir` Text null, `label` (기존; 세트 폴더 이름) |
| `drawing_file` (기존에 추가) | `converter_meta` JSON null (`{zwcad_version, elapsed_s, warnings[]}`), `excluded_reason` String(64) null, `font_names` JSON null (STYLE 테이블 폰트 이름 목록) |
| `compare_set` | `id`, `project_id` FK, `before_set_id` FK drawing_set, `after_set_id` FK drawing_set, `run_date` String(10), `status` String(16), `options` JSON, `stats` JSON null, `created_at`, `updated_at` |
| `sheet_frame` | `id`, `compare_set_id` FK, `role` String(8), `file_id` FK drawing_file, `kind` String(24) (`titleblock` / `unrecognized_file`), `titleblock_handle` String(32) null, `block_name` String(255) null, `bbox` JSON `[x0,y0,x1,y1]`, `sheet_no` Text null, `sheet_title` Text null, `scale_text` String(64) null, `scale_denominator` Integer null, `date_text` String(64) null, `norm_key` Text, `sort_index` Integer, `entity_handles` JSON (list[str]), `provenance` JSON, `attributes` JSON (태그→값 전체) |
| `sheet_pair` | `id`, `compare_set_id` FK, `before_frame_id` FK null, `after_frame_id` FK null, `status` String(24), `match_method` String(16) null, `score` Float null, `sort_key` Text, `change_count` Integer default 0, `minor_count` Integer default 0, `cluster_count` Integer default 0, `compare_dxf_path` Text null, `clusters_json_path` Text null, `warnings` JSON null, `created_at`, `updated_at` |
| `change` | `id`, `pair_id` FK, `seq` Integer, `kind` String(16), `etype` String(32), `layer` String(255), `before_handle` String(32) null, `after_handle` String(32) null, `bbox` JSON, `delta` JSON null, `minor` Boolean, `minor_reason` String(64) null, `provenance` JSON (`{before?, after?}`) |
| `cluster` | `id`, `pair_id` FK, `number` Integer, `signature` String(64) (정렬된 change의 `(kind, before_handle, after_handle)` 튜플 해시), `bbox` JSON, `kind` String(16) (change.kind 값 또는 종류가 섞이면 `mixed`), `label` Text, `user_label` Text null, `decision` String(16) default `pending`, `note` Text null, `change_seqs` JSON (list[int]), `cloud` JSON, `badge` JSON, `updated_at` |
| `run` | `id`, `compare_set_id` FK, `run_date` String(10), `layer_name` String(32), `output_dir` Text, `scope` String(16) (R1은 `all`뿐), `method` String(16) (`auto` / `zwcad` / `acad-ts` / `dxf-only` = `output.dwg_writer`), `pair_ids` JSON, `approved_count` Integer, `ignored_count` Integer, `files` JSON, `status` String(16), `error_message` Text null, `created_at` |

상태 값:
- `compare_set.status`: `ingesting` → `ingested` → `extracting` → `matched` → `comparing` → `compared` (→ `exporting` → `compared`), 실패 `failed`.
- `sheet_pair.status`: `pending`(비교 전) / `changed` / `same` / `added`(후에만) / `removed`(전에만) / `unpaired`(후보 여럿) / `unrecognized`(도곽 미인식 파일) / `converter_mismatch`.
- `sheet_pair.match_method`: `number` / `title` / `position` / `manual`.
- `change.kind`: `added` / `removed` / `modified` / `moved` / `text` / `dimension` / `blockdef`.
- `change.minor_reason`: `move_le_0_01` / `layer_only` / `color_only` / `linetype_only` / `lineweight_only` / `hatch_regen` / `dim_regen` / `mtext_format_only`, 여럿이면 `+`로 잇는다.
- `cluster.decision`: `pending` / `approved` / `ignored`.
- `run.status`: `running` / `done` / `failed`.

repos 함수(R1-01이 `db/repos.py`에 추가): `create_compare_set`, `get_compare_set`, `update_compare_set`, `list_compare_sets`, `replace_frames(session, compare_set_id, role, frames)`, `list_frames`, `replace_pairs`, `list_pairs`, `get_pair`, `update_pair`, `create_manual_pair`, `delete_pair`, `replace_changes(session, pair_id, changes)`, `list_changes`, `replace_clusters(session, pair_id, clusters, keep_decisions=True)`, `list_clusters`, `get_cluster_by_number`, `update_cluster`, `create_run`, `update_run`, `list_runs`, `get_run`. 이름은 고정, 시그니처는 R1-01이 정하고 docstring에 적는다. 부수효과(R1-01 구현): `replace_frames`는 그 compare_set의 짝(과 change·cluster)을 함께 지운다. `replace_changes`·`replace_clusters`는 짝의 집계(`change_count`·`minor_count`·`cluster_count`)를 갱신한다. `create_manual_pair`는 두 프레임이 들어 있던 기존 짝을 먼저 지운다. `delete_pair`는 기본적으로 manual 짝만 지운다. `update_cluster(session, pair_id, number, **fields)`는 없는 컬럼 이름을 거부한다.

## 4. JSON 스키마 (R1-01 소유, `packages/schema/src/compare/*.schema.json`)

| 파일 | 루트 타입 | 쓰는 곳 |
|---|---|---|
| `compare/sheet-frame.schema.json` | `SheetFrame` | API `GET /compare/sets/{id}/pairs`의 frame 요약, DB 직렬화 |
| `compare/sheet-pair.schema.json` | `SheetPair` | API pairs, 사이드카 헤더 |
| `compare/change.schema.json` | `Change` | 사이드카 `changes[]` |
| `compare/cluster.schema.json` | `Cluster` | 사이드카 `clusters[]`, PATCH 응답 |
| `compare/run.schema.json` | `Run` | `GET /compare/runs/{id}`, `run.json` |
| `compare/clusters-sidecar.schema.json` | `ClustersSidecar` | `clusters.json` 전체(`docs/contracts/compare-dxf.md` §7) |
| `compare/compare-set.schema.json` | `CompareSetSummary` | `GET /compare/sets/{id}` |
| `compare/truth.schema.json` | `RevisionTruth` | `fixtures/compare/<scenario>/truth.json`(R1-07이 만들고 R1-06 테스트가 읽는다) |

- 필드 이름은 snake_case, 이 문서 §3의 컬럼 이름과 같다. 좌표는 `common/primitives`의 `point`를 재사용한다. bbox는 compare 계열 전용으로 `compare/sheet-frame.schema.json#/$defs/bbox`(`[x0,y0,x1,y1]` 숫자 4개)를 새로 정의해 쓴다 — `common/primitives`의 `bbox`는 `{min,max}` 객체라 사이드카 형식과 다르다(R1-01 결정). `provenance`는 `common/provenance`.
- 예외: 클러스터의 멤버 목록은 DB 컬럼이 `cluster.change_seqs`(list[int])이고 사이드카·API 필드는 `change_ids`(`ch<seq>`)다(`compare-dxf.md` §7). 같은 정보의 두 표현이며 repos가 변환한다.
- `CompareSetSummary`의 `crosscheck`·`frames`·`pairs`는 해당 단계 전이면 `null`, `converter.before/after`는 변환 전이면 `null`(0건과 "아직 안 함"을 구별한다).
- TS 타입은 `@halo-cad/schema`의 `gen/ts/compare/*`에서 임포트(`import type { SheetPair } from "@halo-cad/schema/gen/ts/compare/sheet-pair"`), 파이썬은 `halo_schema.models.compare.*`. 엔진 라우터의 응답 모델은 pydantic 생성 모델을 **그대로** 쓰거나(권장) 같은 필드의 자체 모델을 쓴다.
- `RevisionTruth`(R1-07·R1-06 공용):
  ```json
  { "schema_version": "0.1", "scenario": "S03_move", "description": "...",
    "before_dir": "before", "after_dir": "after",
    "expected_pairs": [ { "sheet_no": "A-101", "status": "changed", "match_method": "number",
        "expected_changes": [ { "kind": "moved", "etype": "INSERT", "before_handle": "1F3", "after_handle": "1F3",
                                "minor": false, "minor_reason": null, "bbox": [x0,y0,x1,y1], "note": "door moved 1250 east" } ],
        "expected_cluster_count": 2,
        "clean_regions": [ [x0,y0,x1,y1] ] } ],
    "notes": "..." }
  ```
  `before_handle`/`after_handle`은 통째 사본 시나리오처럼 알 수 없으면 `null`이고 그때는 `bbox`로 대조한다. `clean_regions`는 클러스터가 있으면 오탐인 영역.

## 5. 설정 파일 (R1-01 소유 기본값, `engine/src/halo_engine/compare/defaults/`)

`compare/config.py`: `load_compare_config(bundle) -> CompareConfig`, `load_frames_config(bundle) -> FramesConfig`. 기본값 YAML을 번들에 복사(없을 때만)한 뒤 읽고, 프로젝트 파일이 기본값을 키 단위로 덮는다. pydantic 모델, 모든 값에 docstring. `cloud.badge_anchor`·`revtable.anchor`·`frame.boundary`·`frame.fallback`·`frame.assign`은 R1에서 아래 표에 적힌 값 하나만 허용한다(로더가 거부한다). `revtable.col_widths` 길이는 `columns` 길이와 같아야 한다. `ingest.ignore_patterns`는 세트 인입(R1-03)의 정본이며 기존 `project.ignore_patterns`(W3-06)보다 우선한다.

```yaml
  dir_name: "출력"           # <프로젝트>/출력/<run_date>[-n]/
```

### 6.1 `zwcad.py` (R1-02)

```python
@dataclass(frozen=True)
class ZwcadStatus:
    available: bool          # 이 프로세스에서 지금 변환할 수 있는가 (Windows + comtypes + ProgID 등록)
    installed: bool
    version: str | None      # 예: "2026"
    prog_id: str | None      # "ZWCAD.Application" 또는 버전 접미 ProgID
    reason: str | None       # 불가 사유(한국어 아님, 코드: not_windows | comtypes_missing | not_registered | com_error)

def detect() -> ZwcadStatus

@dataclass(frozen=True)
class ConvertResult:
    converter: Literal["zwcad-com"]
    zwcad_version: str
    elapsed_s: float
    warnings: list[str]

class ZwcadError(RuntimeError): ...
class ZwcadTimeout(ZwcadError): ...
class ZwcadUnavailable(ZwcadError): ...

class ZwcadConverter:
    """숨은 인스턴스 하나. with 블록 안에서 파일을 차례로 변환한다."""
    def __init__(self, *, timeout_s: float = 120, dxf_version: str = "2013", com: ComBackend | None = None): ...
    def __enter__(self) -> "ZwcadConverter": ...
    def __exit__(self, *exc) -> None: ...      # 인스턴스 Quit + 프로세스 트리 종료 확인
    def convert_dwg_to_dxf(self, dwg_path: Path, out_dxf: Path) -> ConvertResult: ...
    def convert_dxf_to_dwg(self, dxf_path: Path, out_dwg: Path, *, dwg_version: str = "2013") -> ConvertResult: ...
    def restart(self) -> None: ...

class ComBackend(Protocol):  # 테스트에서 가짜로 바꾸는 유일한 경계
    def create_app(self, prog_id: str) -> Any: ...
    def kill_process_tree(self, pid: int) -> None: ...
```

- 인스턴스 시작 시 시스템 변수 `FILEDIA=0`, `CMDDIA=0`, `PROXYNOTICE=0`, `FONTALT=malgun.ttf`, `Visible=False`. 파일당 `timeout_s` 초과 시 프로세스 트리를 죽이고 `restart()` 후 `ZwcadTimeout`.
- 열기는 읽기 전용(`Documents.Open(path, ReadOnly=True)`), `SaveAs(out, <DXF 버전 상수>)`, `Close(False)`.
- macOS·Linux에서는 `detect().available == False`, `ZwcadConverter()`는 `ZwcadUnavailable`. 계약 테스트는 `ComBackend` 가짜로 Windows 경로를 시뮬레이션한다.
- 라우터 `api/routers/compare_zwcad.py`: `GET /api/v1/compare/zwcad/status` → `ZwcadStatus` JSON.

### 6.2 잡 (R1-03이 `api/jobs.py` 확장, 이후 태스크가 사용)

```python
job = job_manager.create(drawing_set_id=None, compare_set_id=<id>, kind="compare.ingest")   # kind: compare.ingest | compare.frames | compare.run | compare.export
```

## 11. 실행 날짜와 결정론

- `run_date`는 렌더러가 화면 A에서 입력(기본값은 렌더러의 오늘 날짜, e2e는 고정값). 엔진은 `run_date`를 compare_set에 저장하고 비교·출력에 그대로 쓴다. 엔진 코드는 산출물 계산에 `datetime.now()`·`time.time()`·`random`·`uuid4`를 쓰지 않는다(DB `created_at`·잡 타임스탬프·로그는 예외).
- 레이어 `REV-<YYYYMMDD>`; 같은 날 두 번째 출력은 출력 폴더 `출력/<YYYY-MM-DD>-2/`와 레이어 `REV-<YYYYMMDD>-2`(R1-09가 기존 출력 폴더를 세어 정한다). 비교 DXF의 레이어는 접미사 없음.
- 결정론 테스트(R1-06 `engine/tests/compare/test_determinism.py`): 같은 픽스처를 두 번 비교해 `compare.dxf`·`clusters.json` 바이트 동일. R1-09는 `markup.dxf`에 같은 테스트.
