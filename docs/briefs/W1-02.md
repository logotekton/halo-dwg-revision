## Context
엔진 `halo_engine`는 FastAPI 사이드카로 Electron이 spawn한다(`docs/PLAN.md` §3). 아직 코드가 없다. 이 태스크는 패키지 골격, 의존성 핀, READY 핸드셰이크, `/health`, 네이티브 의존성 임포트 테스트, 린트·타입 설정을 만든다. 먼저 읽을 것: `CLAUDE.md`, `docs/PLAN.md` §1·§3, `docs/adr/0002-working-dxf.md`.

## Goal
`cd engine && uv sync && uv run halo-engine serve`가 `127.0.0.1` 임의 포트에 바인드하고 stdout에 `{"event":"ready","port":N,"pid":P,"version":"0.0.1"}` 한 줄을 출력하며, `GET /api/v1/system/health`가 의존성 버전을 반환한다. 모든 네이티브 의존성(ezdxf, shapely, manifold3d, trimesh, ifcopenshell, numpy)이 임포트되고 1줄 연산이 동작함을 테스트가 증명한다.

## Inputs
- 버전 핀(`CLAUDE.md`): Python 3.12, ezdxf 1.4.4, shapely 2.1.x, manifold3d 3.5.x, trimesh 5.x, ifcopenshell 0.8.5, openpyxl, fastapi 0.14x, uvicorn(표준 extras 없이, uvloop 제외), pydantic 2, pydantic-settings, sqlalchemy 2, alembic, typer, httpx(테스트), pytest, pytest-asyncio, hypothesis, ruff, mypy.
- 사이드카 프로토콜 `docs/PLAN.md` §3 1~7항.

## Constraints
- `engine/pyproject.toml`: 프로젝트 `halo_engine`, `requires-python = ">=3.12,<3.13"`, `[project.scripts] halo_engine = "halo_engine.cli:app"`, `[tool.ruff]`(line-length 100, select E,F,I,UP,B), `[tool.mypy]`(`halo_engine.model`, `halo_engine.rules`, `halo_engine.geometry`는 strict — 지금은 빈 패키지여도 설정을 둔다), `[tool.pytest.ini_options]`.
- 루트 `pyproject.toml`은 `[tool.uv.workspace] members = ["engine"]`만. `engine/.python-version`은 이미 `3.12`(루트에 있음; 엔진에도 복사).
- 레이아웃: `engine/src/halo_engine/{__init__,cli,config}.py`, `api/{main,routers/system}.py`, `model/__init__.py`, `rules/__init__.py`, `geometry/__init__.py`, `tests/`.
- `cli.py`(typer): `serve --data-dir PATH --dev --port N --token T --reload`. `serve`는 (1) 토큰을 env `HALO_ENGINE_TOKEN`에서 읽고(없으면 `--token`, 둘 다 없으면 dev 모드에서만 `dev` 허용) (2) `socket.bind(("127.0.0.1", port or 0))` 후 실제 포트로 uvicorn `Server.serve(sockets=[sock])` (3) 바인드 직후 stdout에 READY JSON 한 줄, `flush` (4) `HALO_ENGINE_PARENT_PID`가 있으면 백그라운드 태스크로 5초마다 부모 생존 확인, 죽으면 종료.
- `api/main.py`: FastAPI 앱 팩토리 `create_app(settings)`. 미들웨어: `Authorization: Bearer <token>` 검사(`/api/v1/system/health`는 예외), CORS allow origins `halocad://app`, `http://localhost:5173`, `http://127.0.0.1:5173`. 라우터 `/api/v1/system/health` → `{status:"ok", version, python, deps:{ezdxf, shapely, manifold3d, trimesh, ifcopenshell, numpy, fastapi}}`, `/api/v1/system/capabilities` → `{dwg2dxf: false, ifc_export: true, ...}`(정직하게, 현재 값), `POST /api/v1/system/shutdown`(토큰 필요) → 정상 종료.
- `config.py`: pydantic-settings `Settings(data_dir, dev, log_dir)`; env prefix `HALO_ENGINE_`.
- 로깅: 표준 `logging`, JSON 라인 아님(사람이 읽음), `--log-dir`에 회전 파일.
- 테스트: `tests/test_imports.py`(각 네이티브 dep 임포트 + 1줄 연산: ezdxf `new()`·엔티티 추가, shapely 폴리곤 면적, manifold3d 큐브 부피, trimesh 박스, ifcopenshell `file(schema="IFC4")` 생성·IfcWall 추가, numpy 배열), `tests/test_api.py`(httpx `TestClient`: health 무토큰 200, capabilities 무토큰 401, 올바른 토큰 200), `tests/test_serve.py`(subprocess로 `halo-engine serve --port 0 --token t` 실행 → 첫 stdout 라인이 READY JSON이고 포트로 health 응답 → `POST shutdown`으로 5초 내 종료; 부모 PID 감시는 가짜 PID로 종료되는지).
- `uv.lock` 커밋. `uv sync --frozen`이 이 Mac(arm64)에서 청결해야 한다. 휠이 없어 소스 빌드가 필요한 dep이 있으면 보고서에 명시하고 대안 버전을 제안.
- 문서: `engine/README.md`(설치·실행·테스트, 프로토콜 요약, 한국어).

## Defaults for ambiguity
- ifcopenshell 0.8.5 휠이 Python 3.12 arm64에 없으면 → 3.12용 가장 가까운 0.8.x를 쓰고 Decisions에 기록(계획은 0.8.5).
- uvicorn 표준 extras를 쓰지 않는다(Windows uvloop 문제). `httptools`도 제외.
- 잡 러너·WS는 이 태스크 범위 밖(W2-01·W8-05). 라우터 자리만 `api/routers/__init__.py`에 남긴다.
