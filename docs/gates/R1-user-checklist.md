# R1 사용자 확인 체크리스트 (인쇄용)

이 문서 한 장으로 Windows 노트북에서 Halo DWG Revision 설치본을 확인한다. 결과는 이 종이에
표시로 남기고, 끝나면 `docs/gates/R1.md`에 `R1-GATE <항목>: PASS|FAIL` 줄과 스크린샷·기입값을
옮겨 적는다(원본 판정은 `docs/gates/R1.md`, 이 문서는 확인 중 들고 다니는 작업지다).

## 0. 준비물

- [ ] 설치본 링크: `docs/gates/R1.md`의 "설치본(최종)" 줄 확인 → ______________________________
- [ ] ZWCAD 버전 확인: 시작 메뉴에서 ZWCAD 실행 → 정보/About → 버전이 **2026 Professional**인지
      확인 → 실제 버전: ______________________________
- [ ] 실도면 68장 폴더 경로: ______________________________
      (`samples/2026-09-02-실시도서/` 아래 공종별 폴더 6개: 전기·기계·통신·소방기계·소방전기·건축)
- [ ] 리비전 쌍 폴더 경로: ______________________________
      (`<이름>/{before,after}/` + `planted.md`. 형식은 `samples/revision-pairs/README.md`)
- [ ] 이 PC의 사용자 계정에 관리자 권한이 없어도 된다(설치가 사용자별 설치, `perMachine: false`)

## 1. 설치

1. zip을 내려받아 풀고 `Halo CAD Setup <버전>.exe`를 더블클릭한다.
2. "Windows에서 PC를 보호했습니다" 경고가 뜨면 **추가 정보 → 실행**.
3. 한국어 설치 마법사에서 설치 경로를 확인(기본 `%LOCALAPPDATA%\Programs\Halo CAD`)하고 **설치**.
4. 설치 경로: ______________________________
5. 결과: [ ] 통과  [ ] 실패 — 실패 시 무엇이 멈췄는지: ______________________________

## 2. 실행

1. 설치 마법사에서 "Halo CAD 실행"을 체크하거나 시작 메뉴에서 직접 연다.
2. 상태바 문구: ______________________________ (기대: "엔진: 연결됨 v0.0.1")
3. 결과: [ ] 통과  [ ] 실패
   - 실패 시 로그 확인: `%APPDATA%\Halo CAD\logs\engine.log` → 이 파일을 첨부해 보고한다.

## 3. 실도면 세트 지정 (sheet-count) — 공종 폴더 6개를 한 번씩

"인입 시작" → 화면 B가 뜨면 표의 행 수(또는 상태 필터 "전체" 옆 숫자)를 아래 표에 적는다.

|---|---|---:|---:|---|

## 4. 리비전 쌍 (owner-pair)

1. 화면 A에서 전=`<리비전 쌍>/before`, 후=`<리비전 쌍>/after`로 지정 → "인입 시작".
2. 화면 B에서 "비교 실행".
3. `planted.md`에 적힌 도곽마다 "도곽 열기"로 화면 C를 열어 클러스터를 확인한다.

| 도면번호 | 심은 변경 | 기대 클러스터 수 | 실제 클러스터 수 | 승인/무시 완료 |
|---|---|---:|---:|---|
| | | | | |
| | | | | |

- [ ] 심지 않은 도곽에는 클러스터가 없다(또는 있다면 "접힌 항목"으로 접혀 있다)
- [ ] 클러스터마다 승인 또는 무시를 눌렀다(문구를 하나 이상 직접 편집해 봤다)
- 결과: [ ] PASS(심은 변경 100% 검출, 오탐 0)  [ ] FAIL — 무엇이 다른지: ______________________________
- 스크린샷: `docs/gates/img/R1-owner-pair-01.png`(화면 A), `-02.png`(화면 C)

## 5. 출력 (화면 D → markup-dwg-opens)

1. 화면 B "전체 도곽 출력…" → 실행 날짜 확인 → "출력 실행".
2. 결과 표가 뜨면 "폴더 열기" → 출력 폴더 경로: ______________________________
3. 도면 파일 확장자: [ ] `.dwg`  [ ] `.dxf`(이 경우 `zwcad-manual-check`도 FAIL일 가능성이 높다)
4. 그 파일을 **ZWCAD 2026에서 직접 연다**:
   - [ ] 레이어 목록에 `REV-<오늘 날짜>`가 있고 색이 빨강이다
   - [ ] 승인한 자리마다 구름 + 삼각형 + 번호가 있다
   - [ ] 무시한 자리에는 아무것도 없다
   - [ ] 표제란 왼쪽에 리비전 표(번호·내용·일자)가 있고 행 수 = 승인 건수다
   - [ ] `REV-*` 레이어를 끄면 원본 도면 그대로다
5. "변경 리스트 TSV 복사" → Excel에 붙여넣기(또는 `changes.tsv`를 직접 열기) → 한글이 깨지지
   않는지: [ ] 정상  [ ] 깨짐(어떻게 깨졌는지: ______________________________)
6. 원본 폴더(전·후)의 파일이 수정되지 않았는지(수정 시각 확인): [ ] 그대로  [ ] 바뀜
- 결과: [ ] PASS  [ ] FAIL
- 스크린샷: `docs/gates/img/R1-owner-pair-03.png`(화면 D 결과), `R1-markup-dwg-opens-01.png`(ZWCAD)

## 6. 문제가 생겼을 때

1. 로그를 먼저 확인한다: `%APPDATA%\Halo CAD\logs\engine.log`(엔진), 앱이 아예 안 뜨면
   설치 폴더의 `resources\web` 유무도 함께 본다.
2. 화면을 캡처한다(위 표의 스크린샷 이름 규칙 그대로 `docs/gates/img/`에 저장).
3. `docs/gates/R1.md`의 해당 `R1-GATE <항목>` 줄을 `FAIL`로 바꾸고, 위 표의 값과 로그 파일
   경로·스크린샷 파일 이름을 그 문서의 표 칸에 옮겨 적는다.
4. 판단이 필요한 값(SaveAs 버전 상수, 클라우드 마크 크기, TSV 인코딩 등)은
   `docs/gates/R1-questions.md`에 답을 적는다(해당 Q 번호 옆에 "사용자 답" 한 줄).
5. 확인이 전부 끝나면 `docs/gates/R1.md` 맨 아래 "사용자 승인"에 날짜와 승인 문구를 적는다.
