# W2-08 패키징 스파이크 (macOS arm64)

- Owner model: Sonnet
- Size: 1.5 d
- Branch: `task/W2-08`
- Wave: 2  Phase: P0
- 선행: W1-01, W1-02(main 병합). W2-01과 병행 가능(엔진 spawn 경로는 계약으로 고정)

## Context
개발 모드에서만 동작하는 앱과 엔진이 있다. G0 기준 5번 "mac arm64 패키지 앱이 픽스처를 열고 사이드카가 응답"을 위해 PyInstaller 사이드카와 electron-builder dmg를 만든다. 먼저 읽을 것: `CLAUDE.md`, `docs/contracts/wave-2.md`(패키징 절), `docs/PLAN.md` §1 패키징, `apps/desktop/src/main/protocol.ts`, `engine/pyproject.toml`.

## Goal
`tools/package.sh`가 (1) `engine/dist/halo-engine/` onedir 사이드카를 만들고 (2) `apps/web/dist`와 사이드카를 포함한 `Halo CAD-<version>-arm64.dmg`를 생성한다. dmg에서 설치한 앱이 `halocad://app`으로 UI를 열고 번들된 엔진을 spawn해 health가 응답한다.

```
apps/desktop/build/**                  # entitlements.mac.plist, icon placeholder

```

## Forbidden
`apps/desktop/src/main/engine/**`(W2-01 소유), `apps/web/**`, `packages/**`, `tools/verify.sh`, 루트 설정.

## Constraints
- PyInstaller 6.22 onedir, 엔트리 `halo_engine.cli:app`을 감싸는 `engine/src/halo_engine/__main__.py`(없으면 만들되 W1-02 산출과 충돌하지 않게 최소), `multiprocessing.freeze_support()`. hidden imports/데이터: ifcopenshell(스키마 파일·동적 모듈), shapely(GEOS dylib), manifold3d, trimesh, uvicorn 로거·워커 모듈, typer. 결과 `engine/dist/halo-engine/halo-engine` 실행 시 READY 라인이 나와야 한다.
- electron-builder: `appId: kr.co.daemyung.halocad`, `productName: Halo CAD`, mac `target: [dmg, zip]`, `arch: [arm64]`, `hardenedRuntime: false`(현 단계), `identity: null`(ad-hoc), `extraResources`: 사이드카 → `engine/`, `apps/web/dist` → `web/`. asar 사용.
- `protocol.ts`: 계약대로 `app.isPackaged`로 분기. 개발 모드 동작을 깨지 않는다(테스트 유지).
- `smoke-packaged.mjs`: `dist/mac-arm64/Halo CAD.app/Contents/MacOS/Halo CAD`를 `HALO_E2E_SMOKE=1`로 실행 → stdout의 `E2E_WINDOW_TITLE:Halo CAD` 확인, W2-01이 병합돼 있으면 상태바 "연결됨" 스크린샷 확인, 120초 내 exit 0.
- 코드 서명·공증은 하지 않는다. Gatekeeper 우회 절차를 `docs/dev/packaging.md`에 적는다(시스템 설정 → 개인정보 보호 및 보안 → "확인 없이 열기").
- 산출물 크기와 빌드 시간을 보고서에 기록.
- `tools/package.sh`: 순서 = 사이드카 빌드 → `pnpm build` → electron-builder. 실패 시 즉시 중단(`set -euo pipefail`).

## Definition of done
- `tools/package.sh` 성공, dmg 생성.
- `engine/dist/halo-engine/halo-engine serve --dev --port 0 --token dev`가 READY 출력(번들 단독 실행).
- 설치된 앱 스모크 통과(`smoke-packaged.mjs`).
- 개발 모드 `pnpm dev` 여전히 정상(회귀 없음).
- `tools/verify.sh` 녹색. `docs/dev/packaging.md` 작성.
- 커밋 `W2-08: ...` on `task/W2-08`.

## Acceptance checks (Fable이 실행)
```bash
tools/package.sh                                            # expected: dist/*.dmg
engine/dist/halo-engine/halo-engine serve --dev --port 0 --token dev | head -1   # expected: READY JSON
node apps/desktop/scripts/smoke-packaged.mjs                # expected: exit 0, title line printed
```

## Defaults for ambiguity
- 아이콘은 단색 placeholder PNG→icns(전용 도구 없이 `iconutil`은 macOS 기본 제공).
- ifcopenshell 수집이 까다로우면 PyInstaller `collect_all('ifcopenshell')`.
- Intel mac x64와 Windows는 이 태스크 범위 밖(W5-05, CI).

## Reference implementation
electron-builder 공식 `extraResources` 문서, PyInstaller `collect_all` 패턴.
