## Context
`packages/cad-core`는 헤드리스 절반(열기·통계·NDJ)만 있다. 이 태스크가 뷰(WebGL) 절반과 DWG 변환기를 만든다. 먼저 읽을 것: `CLAUDE.md`, `docs/dev/cadhost-proposal.md`, `docs/contracts/wave-3.md`, `docs/adr/0002-working-dxf.md`(개정 절), `docs/adr/0004-three-isolation.md`, `docs/spikes/mlightcad-api.md`(A, B, C.3~C.6, C.8~C.10, D), `docs/spikes/large-file.md` §4·§5, `packages/cad-core/README.md`와 `src/**`, `packages/dwg-io-gpl/README.md`, `spikes/mlightcad/src/main.ts`, `spikes/mlightcad/scripts/bench-dxfout.cjs`, `apps/desktop/src/main/{index,protocol,window}.ts`, `docs/contracts/stats-definition.md`.

## Goal
1. `CadHost`(`packages/cad-core/src/host/`)가 `#viewer-root`에 mlightcad 뷰를 마운트하고 정본 DXF 바이트를 열어 렌더한다. 선택·하이라이트·줌·오버레이·레이아웃 전환·undo/redo·명령 실행이 제안서 표면대로 동작하고, `dispose()`가 싱글턴 5종을 정리한다.
2. 데스크톱 main이 **숨김 BrowserWindow**에서 DWG→DXF 변환(`dxfOut()` + INSERT 66 · HATCH 92 후처리)을 수행하고 `halocad:convert:dwg-to-dxf`로 노출한다. 실패 시 acad-ts 폴백.
3. 뷰어 자산(워커·wasm·fonts.json)이 `halocad://app/viewer/` 아래 배치되고 커스텀 스킴이 wasm MIME·HEAD를 처리한다.
4. 스플라인 길이를 NURBS 자체 평탄화로 계산해 F01의 `length_sum_mm`이 ezdxf truth ±0.1% 안에 든다(화이트리스트 W01 제거 가능).
5. 렌더러 `features/viewer`가 CadHost를 사용해, 스토어의 문서를 열고 선택 이벤트를 `selection` 스토어에 반영한다.

## Constraints
- mlightcad 임포트는 여전히 `mlightcad-surface.ts`(와 `dwg-io-gpl`)에서만. ESLint 규칙 유지.
- 정확 버전 고정 유지. `three@0.172.0`.
- 숨김 창 변환기: `BrowserWindow({show:false})` + 전용 preload, `halocad://app/convert.html`. 요청마다 창을 재사용, 5분 유휴 시 파괴. 결과 DXF는 지정 경로에 저장, `entity_count`·`converter`·`warnings`를 반환. 후처리는 문자열 스트림에서 INSERT 그룹 66과 HATCH 92 비트만 수정하고 그 외 바이트를 바꾸지 않는다(테스트: F06.dxf→dxfOut→후처리→ezdxf 통계 = truth. ezdxf 검증은 `cd engine && uv run halo-engine stats`로).
- 폴백: acad-ts `dwg2dxf` 후 산출물에 ATTRIB 서브클래스/태그 수복이 필요하면 **하지 않고** "acad-ts 폴백은 엔진 교차검증 실패 시 사용자에게 안내"로 둔다(W3-08이 라이터 결함을 다룸).
- 대용량: 열기 전 크기 밀도(DXF 207 B, DWG 26 B/엔티티)로 티어 추정, 25만 초과면 계약 문구로 경고 이벤트 `openProgress`에 실어 보낸다(라이트 DXF 생성은 W3-08/엔진).
- 뷰 성능: F11(20만, 로컬 생성) 열기 후 pan/zoom 60fps 근접 여부와 RSS를 문서에 기록(뷰어 렌더 포함 A 경계 재확인).
- 테스트: vitest 단위(후처리, NURBS 길이 vs ezdxf truth F01, 상태 머신), Playwright e2e `tests/e2e/viewer.spec.ts`: `HALO_E2E_PICK_FILES`로 F06.dxf와 F06.dwg를 열어 렌더 완료(`renderIdle`), 레이어 5개, 핸들 클릭 하이라이트, 스크린샷. 힙 누수 테스트(20파일 순차 열기/닫기 <10%).
- `docs/dev/viewer-integration.md`: 자산 배치, CSP, 변환 창, 알려진 제한.

## Defaults for ambiguity
- 워커·wasm 자산은 빌드 시 복사(커밋하지 않음), `pnpm build` 전 스크립트로.
- 변환 창은 `halocad://` 오리진(워커·wasm 로딩 조건 충족).
- NURBS 평탄화 허용오차 0.01mm 상당(ezdxf `flattening(0.01)`과 동일 정의).
