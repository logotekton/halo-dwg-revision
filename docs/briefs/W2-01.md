## Context
Electron 골격(`apps/desktop`, `apps/web`)과 엔진 골격(`engine/`, READY 핸드셰이크·health·shutdown)이 main에 있다. 이 태스크가 둘을 연결한다: main 프로세스가 엔진을 spawn하고 상태를 관리하며, 렌더러가 엔진을 호출할 수 있게 한다. 먼저 읽을 것: `CLAUDE.md`, `docs/contracts/wave-2.md`(계약), `docs/PLAN.md` §3, `apps/desktop/src/main/*.ts`, `apps/desktop/src/preload/*.ts`, `engine/src/halo_engine/cli.py`, `engine/README.md`.

## Goal
`pnpm dev`를 실행하면 Electron이 엔진을 자동으로 띄우고 상태바에 "엔진: 연결됨 v0.0.1"이 표시된다. 엔진 프로세스를 강제 종료하면 "재연결 중"을 거쳐 다시 연결되고, 3회 실패하면 "엔진 시작 실패"와 로그 경로를 보여준다. 앱 종료 시 엔진도 5초 내 종료된다.

## Constraints
- 토큰은 `crypto.randomBytes(32).toString('hex')`, env로만 전달. 로그에 토큰을 남기지 않는다.
- READY 파서는 stdout을 줄 단위로 읽고 첫 JSON 줄만 해석, 나머지 stdout/stderr는 `<userData>/logs/engine.log`로 흘린다(electron-log 도입 가능, MIT).
- 개발 모드 spawn: `uv run halo-engine serve ...`를 `engine/` cwd에서. `uv`가 PATH에 없으면 `$HOME/.local/bin/uv`를 시도, 그래도 없으면 `failed` 상태와 안내 메시지("uv가 설치되어 있지 않습니다").
- 프로덕션 spawn 경로는 계약대로 `<resourcesPath>/engine/halo-engine`. 바이너리가 없으면 `failed` + 메시지(W2-08 전까지는 정상).
- 부착 모드(`HALO_ENGINE_URL`)에서는 spawn과 재시작을 하지 않고 health 폴링만.
- health 폴링 500ms 간격, 30초 타임아웃. 크래시 감지는 프로세스 `exit` 이벤트. 재시작 백오프 1s/3s/9s, 3회 후 `failed`.
- 종료: `before-quit`에서 `POST /system/shutdown`(Bearer) → 5초 대기 → 살아 있으면 `SIGTERM`(Windows `taskkill /T /F`) → 자식 트리까지 정리.
- 렌더러: `engine.ts`는 `getConnection()` 결과를 메모이즈. 상태바는 `onStatus`로 갱신. 모든 문자열은 ko.json 키.
- `HALO_E2E=1`일 때만 `window.__haloTest.getStatus()` 노출(현재 상태 문자열).
- 엔진 측: `request.headers.get("authorization") != f"Bearer {token}"`를 `secrets.compare_digest`로 바꾸고 테스트 추가. 다른 엔진 코드는 건드리지 않는다.
- 단위 테스트(vitest, `apps/desktop`): READY 파서(정상/깨진 JSON/READY 전 잡음 줄), 백오프 시퀀스, 상태 머신 전이(순수 함수로 분리). 통합 테스트(`apps/desktop` `test:integration` 스크립트, uv 필요): 실제 엔진 spawn → ready → health → kill → restarting → ready → shutdown. `pnpm -r test`에는 단위만, 통합은 별도 스크립트로 두고 verify.sh 패치 제안에 포함.

## Definition of done
- `pnpm dev`: 상태바 "엔진: 연결됨 v0.0.1". 터미널에서 엔진 PID kill → 상태바 "재연결 중" → 다시 "연결됨". 앱 종료 후 `pgrep -f halo-engine` 없음.
- `HALO_ENGINE_URL=http://127.0.0.1:8765 HALO_ENGINE_TOKEN=dev pnpm dev`(엔진은 별도 `uv run halo-engine serve --dev --port 8765 --token dev`)에서 spawn 없이 연결.
- 단위·통합 테스트 통과, `tools/verify.sh` 녹색, `cd engine && uv run pytest -q` 통과.
- `docs/dev/engine-sidecar.md`: 상태 머신 그림(텍스트), 로그 위치, 부착 모드 사용법.
- 커밋 `W2-01: ...` on `task/W2-01`.
