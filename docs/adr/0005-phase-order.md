# ADR-0005 단계 순서: CAD → DMS → 3D 재구성 → 적산

상태: 승인 (2026-09-02)

## 맥락
사용자 지시는 (1) 무료 CAD, (2) 적산, (3) 도면관리다. 2026-09-02 사용자가 실행 순서를 **1 → 3 → 2** 로 확정했고, 2 안에서는 **3D 모델링을 먼저** 완성한 뒤 적산을 **구조 → 내부마감 → 외부마감** 순으로 붙이도록 지시했다.

## 결정
P0 스택 스파이크 → P1 CAD 워크스테이션 → P2 도면관리(DMS) → P3 3D 재구성 → P4 적산 구조 → P5 적산 내부마감 → P6 적산 외부마감.

## 결과
- DMS 서버 인프라(호스트, PostgreSQL, 인증 방식) 결정이 P1 종료(11월 초)로 앞당겨진다. 지연 시 SQLite + 공유폴더로 같은 API를 먼저 만든다.
- 골든셋(적산 산출서)은 P4 진입(3월 초)까지 필요하다.
- "변경 도면 물량 비교"는 DMS 단계가 아니라 각 적산 트랙 완료 시 추가된다. DMS 단계에서는 도면 엔티티 diff까지만.
- P3의 게이트는 물량이 아닌 **모델 정확도**(부재·레벨·실·면의 도면 대비 일치)로 정의한다. 3D 검수 UI로 가치를 조기에 보인다.
- 적산 룰(P4~P6)은 P3의 모델을 읽기만 하고 바꾸지 않는다.
