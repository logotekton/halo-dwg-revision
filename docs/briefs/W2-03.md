## Context
엔진 골격만 있다. 이 태스크가 파일 인입 경로의 엔진 측을 만든다: DXF 로드(복구 포함), 인코딩 보정, XREF 임베드, 작업용 DXF 정본 생성, 레이어 통계(`stats.py`). 또한 W1-03의 truth 파일이 새 통계 계약과 형식이 달라 **재생성**한다. 먼저 읽을 것: `CLAUDE.md`, `docs/contracts/stats-definition.md`, `docs/adr/0002-working-dxf.md`, `packages/schema/src/stats/layer-stats.schema.json`, `packages/schema/src/common/primitives.schema.json`, `fixtures/README.md`, `fixtures/gen/src/fixtures_gen/stats.py`, `engine/README.md`.

## Constraints
- **통계 계약을 문자 그대로.** ATTRIB는 `insert.attribs`로 수집해 `text_count`/`text_hash`에 포함, `count_by_type`에서 제외. MTEXT는 원본 `mtext.text`(제어코드 포함). 해시는 NFC → 코드포인트 정렬 → `\n` 결합 → sha1 앞 16 hex. 버킷 `(space, layer)`, 페이퍼 공간은 `PAPER:<layout name>`.
- 엔진 `stats.py`와 `fixtures_gen/stats.py`는 **서로 임포트하지 않는다**(독립 구현 유지). 두 결과가 F01~F10에서 바이트 동일(JSON 정렬 직렬화)해야 한다.
- 스키마 검증: 엔진 테스트는 `jsonschema` + `referencing`으로 `packages/schema/src/**/*.json`을 `$id` 레지스트리에 올려 검증(W1-05의 `gen/python/halo_schema/validation.py` 방식 참고, 그러나 그 패키지를 의존성으로 넣지는 않는다 — 루트 워크스페이스가 제외하고 있음).
- `dxf_loader.py`: `ezdxf.readfile` → 실패 시 `ezdxf.recover.readfile`, 감사 결과(`auditor.errors`)를 반환 구조에 포함. `$DWGCODEPAGE`, `$ACADVER`, `$INSUNITS`, `$FINGERPRINTGUID` 추출.
- `encoding.py`: R2007 이전 파일에서 선언 코드페이지로 디코드한 결과의 모지바케 점수(한글 음절 U+AC00~D7A3 비율 vs U+00C0~00FF·U+FFFD 비율)를 계산, 나쁘면 cp949로 재시도, `codepage_effective` 기록. `\M+1XXXX`(MIF) 및 `\U+XXXX` 디코드. F03 cp949 변형 → R2018 변형과 텍스트 집합 동일 테스트.
- `xref.py`: `ezdxf.xref` 모듈로 호스트에 참조 도면 임베드. 해석 순서(ADR-0002 §XREF): 저장 절대경로(세트 내) → 호스트 동일 폴더 → 상대경로 → 지정 검색경로 → 확장자·대소문자 무시 basename. 임베드 시 재번호된 핸들 맵 `{xref_file, original_handle, bound_handle}` JSON 출력. F10 호스트 테스트.
- `working_dxf.py`: 위 셋을 조합해 `<sha256>.working.dxf`(AC1032, UTF-8)와 `<sha256>.working.json`(메타: 원본 sha256, 코드페이지, 감사 오류 수, 핸들 맵 경로, 통계 경로)을 쓴다. 미지원·프록시 엔티티는 ezdxf가 보존하는지 확인하는 테스트(프록시가 포함된 최소 DXF를 테스트에서 생성).
- `entity_index.py`: 최상위 엔티티마다 `(handle, etype, layer, space, bbox, length, area, text, block_name)` 레코드 생성기(SQLite 저장은 W6-01, 지금은 iterable/JSONL만).
- CLI: `halo-engine ingest <path> --out <dir> [--search-path P]...`, `halo-engine stats <path> --out <json>`. stdout에는 결과 경로만.
- 픽스처 truth 재생성: `fixtures_gen/pipeline.py`가 `F##.json`(LayerStatsDocument, `producer: "fixtures-gen"`, `file_sha256`은 생성 DXF의 sha256)과 `F##.extra.json`(기존 `extra`)을 쓴다. DXF 산출물은 바뀌지 않아야 한다(재생성 후 `git status`에 `fixtures/generated` 변경 0). 결정론 테스트 유지.
- 성능: F11(로컬 생성) stats < 10초.

## Defaults for ambiguity
- `text_hash`에서 빈 텍스트 집합은 빈 문자열의 sha1 앞 16자리.
- XREF 임베드 시 레이어명 충돌은 ezdxf 기본(`xref$0$layer`)을 따르고 맵에 기록.
- `PAPER:` 레이아웃명은 DXF 레이아웃 이름 그대로(`Layout1`).
- F11 truth는 유지(totals만), F12는 커밋하지 않음.
