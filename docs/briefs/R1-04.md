## Context
비교 단위는 파일이 아니라 도곽(표제란 INSERT 하나 = 시트 하나)이다. 실도면 68장은 전부 모델공간 단독이며 한 파일에 도곽이 여러 개(전기 104, 기계 51, 통신 28, 소방기계 45, 소방전기 28, 건축 99)다. 표제란이 XREF 안에 있는 파일(표지·XR 참조)은 W3-06이 XREF를 임베드한 작업용 DXF에서 중첩 INSERT로 나타난다. 먼저 읽을 것: `CLAUDE.md`, `docs/contracts/r1.md` §1·§3·§5(`frames.yaml`)·§6·§7·§12, `docs/contracts/compare-dxf.md` §1(좌표·offset), `docs/spikes/real-dwg-measurement.md`(도곽·XREF 실측), `engine/src/halo_engine/compare/{config,ingest_set}.py`, `db/repos.py`(R1-01 함수), `api/routers/compare_sets.py`·`api/jobs.py`(`run_job`, `ProgressReporter`), `ingest/entity_index.py`(bbox·space 헬퍼), `ingest/xref.py`(임베드 블록 이름 규칙), `fixtures/compare/README`·`S13_multi_sheet`·`S16_unrecognized`·`S17_scale_50`(R1-07).

## Goal
1. `compare/frames.py`
   - `extract_frames(doc, *, file_id, config: FramesConfig) -> list[FrameRecord]`: 모델공간의 INSERT(깊이 ≤ 2로 임베드 XREF 블록 안도 탐색, 변환 행렬 누적)에서 ATTRIB ≥ `min_attribs`인 후보를 모으고, 태그가 `number_tags` 중 하나 **또는** `title_tags` 중 하나에 맞으면 표제란 확정. 태그가 하나도 안 맞으면 `fallback_most_common_block`(같은 블록 이름이 가장 많이 반복되는 후보). `block_name_patterns`가 있으면 그 이름만.
   - 도곽 경계: (a) 표제란 bbox를 완전히 포함하는 가장 작은 축 정렬 닫힌 사각형 LWPOLYLINE(정점 4~5, 각 변 수평·수직 ±1°) → (b) 없으면 같은 세트에서 관측된 도곽 크기 최빈값을 표제란 오른쪽 아래 기준으로 적용 → (c) 그것도 없으면 A1(841×594)×`scale_denominator`(없으면 100)를 표제란 오른쪽 아래 기준으로. 어떤 경로였는지 `FrameRecord.boundary_source`에 남긴다.
   - `sheet_no`·`sheet_title`·`scale_text`·`date_text`는 ATTRIB 문자열, `attributes`는 태그→값 전체. `parse_scale("1:100" | "1/100" | "A3 1:100" | "SCALE 1:50")` → 분모 int, 못 읽으면 `None`. `normalize_key(text, config)`: 공백 제거·전각→반각·대문자·하이픈 통일(`–`·`—`·`_`→`-`).
   - `assign_entities(doc, frames)`: 모델공간 최상위 엔티티(임베드 XREF INSERT 포함)의 bbox 중심이 들어가는 도곽에 배정. 여러 도곽에 걸치면 중심이 든 쪽, 중심이 어느 도곽에도 없으면 미배정. `entity_handles`는 정렬된 핸들 목록. bbox는 `ezdxf.bbox.extents`(캐시 사용).
   - 표제란이 하나도 없는 파일은 `kind="unrecognized_file"` 프레임 1개(bbox = 도면 extents, `norm_key="file:<정규화 파일명>"`).
   - `sort_index`: 파일 안 읽는 순서(위→아래, 왼쪽→오른쪽; y는 도곽 높이의 절반 단위로 묶어 행을 만든 뒤 x 정렬).
   - `provenance = {file: <file_id>, handle: <표제란 handle>, path: [<바깥 INSERT 핸들...>], space: "MODEL"}`.
2. `compare/match.py` — `match_frames(before, after, config) -> list[PairRecord]`, 계약의 4단계:
   1. 정규화 도면번호 동일(양쪽에서 유일) → `number`, score 1.0.
   2. 남은 것 중 제목 토큰(공백·하이픈·괄호 분리) 자카드 ≥ `title_jaccard_min`이고 양쪽에서 유일한 최고 → `title`, score = 유사도.
   3. 같은 파일 이름(정규화) 안에서 `sort_index` 같고 도곽 크기 ±1% → `position`, 0.5.
   4. 나머지: 전에만 → `removed`, 후에만 → `added`, 후보가 여럿(동점) → `unpaired`(양쪽 프레임을 각각 `unpaired` 짝으로).
   - `unrecognized_file` 프레임은 같은 파일명끼리 짝지어 `status=unrecognized`(비교 대상 아님, 목록에는 보임).
   - 짝의 `status`는 비교 전이므로 `pending`(같은 파일이 sha 캐시 히트로 전·후 동일이면 바로 `same`). `converter_mismatch`: 전·후 파일의 `drawing_file.converter`가 둘 다 있고 다르면.
   - `sort_key`: 도면번호 자연 정렬 키(숫자 부분 0패딩), 없으면 제목, 없으면 파일명+sort_index.
3. 라우터 `api/routers/compare_pairs.py`
   - `POST /compare/sets/{id}/frames` → 202 `{job_id}`(잡 `compare.frames`): 파일마다 프로세스 풀에서 `ezdxf.readfile` + `extract_frames` + `assign_entities`(피클 가능한 dataclass로 반환) → `repos.replace_frames` → `match_frames` → `repos.replace_pairs`(수동 짝은 보존) → `compare_set.status=matched`, `stats.frames/pairs` 갱신. 상태가 `ingested`·`matched`·`compared`가 아니면 409.
   - `GET /compare/sets/{id}/pairs?status=&q=&sort=` → `[SheetPair]`(스키마 생성 모델, `before_frame`/`after_frame` 요약 포함: id·sheet_no·sheet_title·file_name·scale_denominator·kind). `q`는 도면번호·제목·파일명 부분 일치(정규화 후), `sort`는 `sheet_no`(기본)·`status`·`changes`.
   - `POST /compare/sets/{id}/pairs/manual {before_frame_id, after_frame_id}` → 두 프레임이 각각 `removed`/`added`/`unpaired` 짝에 속해 있어야 하고, 그 짝들을 지우고 `manual` 짝 하나를 만든다(`status=pending`). `DELETE /compare/pairs/{pair_id}`는 `manual`만 → 원래의 `removed`/`added` 짝을 복원.
4. `CompareSetSummary.frames`·`pairs` 카운트를 `compare_sets.py`의 요약 계산이 읽을 수 있게 `stats`에 쓴다(요약 함수가 `stats`를 그대로 내보내면 `compare_sets.py`를 고치지 않아도 된다; 고쳐야 하면 패치 제안).

## Defaults for ambiguity
- 표제란 INSERT가 도곽 사각형 밖에 있으면(드묾) 그 INSERT의 bbox를 포함하도록 경계를 넓힌다.
- 같은 도면번호가 한 세트 안에 둘 이상이면 번호 매칭을 건너뛰고 제목·위치로 간다(보고서에 건수).
- `scale_denominator`를 못 읽으면 `None`(비교·마크업은 배율 1.0).
- 임베드 XREF 안의 표제란은 깊이 2까지만. 더 깊으면 무시하고 경고.
- 실도면 테스트가 acad-ts 변환 실패로 파일을 건너뛰면 건너뛴 파일 목록을 표에 적는다.
