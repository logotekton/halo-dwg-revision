## Goal
1. **앱 셸:** `App.tsx`가 `AppHeader`(제목 + 단계 표시 `A 세트 지정 · B 도곽 목록 · C 검토 · D 출력`, 현재 단계 강조) + `features/compare/CompareApp.tsx` + `StatusBar`만 렌더한다. 도크·탭·명령줄·메뉴·files·xref 기능은 파일을 지우지 않고 렌더에서만 뺀다. 관련 테스트(`App.test.tsx` 등)를 새 셸에 맞춘다. `index.html`의 제목은 유지(`Halo CAD`).
2. **다크 테마 토큰:** `styles/index.css`에 계약 §9의 CSS 변수와 기본 컴포넌트 클래스(패널·버튼·칩·표·입력). Tailwind는 기존대로 쓰되 색은 변수로.
3. **상태:** `state/compare.ts`(계약 §9 필드·액션). 잡 진행은 기존 WS/폴링 방식을 재사용(없으면 `GET /jobs/{id}` 500ms 폴링). `features/compare/api.ts`: `getZwcadStatus`, `createSet`, `getSet`, `getSetFiles`, `startFrames`, `getPairs`, `createManualPair`, `deletePair`, `startRun`, `getJob`.
4. **화면 A `SetScreen.tsx`:** 전 폴더·후 폴더 선택 버튼(IPC `pickFolder`), 선택 경로 표시, 실행 날짜 입력(`<input type="date">`, 기본값 오늘), ZWCAD 상태 칩(`available`이면 "ZWCAD 변환", 아니면 "자체 변환기"와 사유), "인입 시작" → `createSet` → 잡 진행 바(단계·n/N·파일 이름) → 완료 시 자동으로 `startFrames` → 완료 시 화면 B로. 요약 카드(파일 수·변환 성공·실패·제외·폰트 누락 목록·교차검증 결과)와 실패 파일 목록(에러 메시지).
5. **화면 B `SheetListScreen.tsx`:** 표(도면번호·도면명·파일·상태 칩·변경 수·매칭 방법·축척), 상태 필터 칩(전체·변경·동일·신규·삭제·짝 없음·미인식·변환기 불일치·대기), 검색, 정렬. "짝 없음" 행에서 수동 짝 맞춤 다이얼로그(전에만 있는 도곽 목록 ↔ 후에만 있는 도곽 목록 선택 → `createManualPair`), 수동 짝 해제. 버튼: **비교 실행**(`startRun` 잡 → 완료 후 목록 새로고침), **도곽 열기**(선택 행 → `openPair` → 화면 C), **전체 도곽 출력**(→ 화면 D). 비교 전에는 도곽 열기·출력 버튼 비활성.

## Constraints
- UI 문자열은 `ko.json` 키만(ESLint `no-literal-string`). 상태 칩 색은 테마 변수.
