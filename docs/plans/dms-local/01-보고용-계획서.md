## 1. 배경과 현재의 문제
1.1 현재 도면 관리 방식(폴더·메일·메신저)과 그로 인한 문제: 최신본 식별 불가, 변경 이력 부재, 동일 도면 사본 난립(`_recover`, 날짜 접미사), XREF 깨짐, 폰트 불일치.
1.2 실도면 실태조사 결과(2026-09-02 실시도서 68장 기준): 모델공간 단독·도곽 단위 시트, XREF 133건 전부 상대경로, 누락 폰트 52종, 공종별 PDF 존재. → "관리 단위는 파일이 아니라 도곽"이라는 설계 근거.
1.3 왜 지금인가: Windows PC·ZWCAD 라이선스 확보, 무료 스택 검증 완료(P0), 실도면 확보.

## 2. 목표와 범위
2.1 목표: 한 문장 목표 + 측정 가능한 목표 3개(예: 최신본 식별 100%, 변경 도면 파악 시간 X분→Y분, 검색 시간).
2.2 이번 단계 범위(로컬 전용): 체크인/체크아웃, 리비전 이력, 도곽 단위 메타데이터·검색, CAD 없는 열람(뷰어·PDF), 리비전 비교(diff), 승인 기록, 백업.
2.3 범위 제외: 별도 서버·클라우드·외부(발주처·협력사) 공유·알림·권한 체계·물량 비교(적산 단계).
2.4 전체 로드맵에서의 위치: 1 CAD(보류) → **3 DMS(이번)** → 2 적산(3D 재구성 → 구조 → 마감). 순서 변경 사유(ZWCAD 도입으로 편집기 자체 개발 불필요).

## 3. 제안 솔루션 개요
3.1 구성도(그림): ZWCAD 애드인 ↔ 저장소(공유 폴더) ↔ 로컬 DMS 앱(뷰어·검색·비교·승인).
3.2 사용자 시나리오 3개: (a) 설계 담당의 체크아웃→수정→체크인, (b) 현장·관리자의 열람·검색·비교(CAD 없이), (c) 승인자의 리비전 승인.
3.3 기존 방식과의 비교표(폴더 관리 / 상용 DMS(Autodesk Vault 등) / 본 제안): 비용·설치·CAD 종속·확장성.
3.4 자체 개발이 타당한 이유: 상용 DMS 라이선스 비용 vs 사내 요구(도곽 단위·적산 연계·ZWCAD).

## 4. 기대 효과
4.1 정량: 검색·확인 시간, 구버전 사용 사고 0, 변경 파악 시간. [채울 것: 현재 값 측정 방법]
4.2 정성: 이력 투명성, 신규 인원 온보딩, 적산 자동화의 입력 데이터 확보(도곽·리비전 체계가 곧 적산의 기초).

## 5. 기술 방식(비전문가용 요약)
- 무료·오픈소스 기반(총 라이선스 비용 0), 사내 전용 사용 조건과 라이선스 준수(GPL 격리, ODA 미사용).
- 원본 도면 불변 원칙(원본은 절대 덮어쓰지 않음, 파생물만 생성).
- ZWCAD 활용: 애드인으로 체크인 시 DXF·PDF·썸네일 자동 생성 → 변환기 개발 불필요.
- 이미 검증된 자산: 엔진(파일 인입·통계·교차검증), 스키마, 셸, 실도면 실측 결과.

## 6. 단계별 일정과 산출물
| 단계 | 내용 | 산출물 | 게이트(통과 기준) |
|---|---|---|---|
| M1 저장소·체크인 | 공유 폴더 저장소, 애드인 체크인/아웃, 리비전 이력 | 애드인 v0, 저장소 규격 | 실도면 세트 68장 등록·체크아웃·체크인 왕복 |
| M2 열람·검색 | 로컬 앱 뷰어, 도곽 단위 메타데이터·검색, PDF/썸네일 | 로컬 앱 v0 | CAD 없는 PC에서 검색·열람 |

| M4 파일럿 | 부서 1곳 실사용 4주 | 파일럿 보고서 | 재사용 의사·개선 요청 목록 |

## 7. 리스크와 대응
- 공유 폴더 동시 편집 충돌 / 애드인 ZWCAD 버전 종속 / 폰트·XREF 품질 / 사용 정착(교육) / 서버 없는 구조의 한계(알림·권한) → 각 대응.

## 8. 소요 자원과 비용
- 라이선스: ZWCAD 좌석 수(설계 담당 n명), 소프트웨어 비용 0(오픈소스).
- 하드웨어: Windows PC(확보), 공유 폴더/NAS(기존 사용 여부 확인).
- 인력: 개발은 AI 오케스트레이션(Claude), 담당자 스티어링 시간(주 n시간), 파일럿 부서 협조.
- 외부 비용: 0 예상. [채울 것: Apple 개발자 계정 등 선택 항목]

## 9. 성과 지표와 검증
- KPI 3~5개와 측정 방법, 파일럿 판정 기준(정량+설문).

## 10. 의사결정 요청 사항
1. 저장소 위치(기존 NAS/공유 폴더 vs 신규) 2. ZWCAD 에디션·좌석 수 3. 파일럿 부서와 기간 4. 승인 절차 정의(누가·언제) 5. 도면번호 체계 확정 6. 폰트 파일 제공·라이선스 확인.
