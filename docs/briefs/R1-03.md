## Goal
1. `POST /api/v1/compare/sets {before_dir, after_dir, project_dir?, run_date, options?}` → 202 `{compare_set_id, project_id, job_id}`. 검증: 두 폴더가 존재하는 디렉터리, `run_date`는 `YYYY-MM-DD`. `project_dir` 기본값은 계약 §1(공통 부모). 번들은 `<project_dir>/.halo`에 `open_bundle`/`create_bundle`하고 `app.state.bundle`로 둔다. `drawing_set` 두 행(`role`, `label`=폴더 이름, `source_dir`), `drawing_file` 행(정렬: 이름 대소문자 무시 오름차순; `ingest.ignore_patterns`에 걸리면 `import_status=EXCLUDED`, `excluded_reason="ignore_pattern"`), `compare_set`(`status=ingesting`, `options`, `run_date`).
2. 잡 `compare.ingest`(`api/jobs.py`에 계약 §6.2의 `create(kind=, compare_set_id=)`, `run_job`, `ProgressReporter`를 추가하고 기존 `run_drawing_set_import`는 그대로 둔다). 파일 순서: 전 세트 → 후 세트. 파일마다:
   - `copy_original_step`(sha256, `originals/`). **sha 캐시:** 같은 sha256의 `cache/dxf/<sha>.working.dxf`와 `stats`가 이미 있으면 변환·정본 생성을 건너뛰고 행에 `converter_meta.cache_hit=true`.
   - DXF 입력: 변환 없음. DWG 입력: `pick_converter(zwcad.detect(), options.converter)` — `auto`는 ZWCAD 가능하면 `zwcad-com`, 아니면 기존 경로(`builtin` = WS `convert.request` → 데스크톱 dxfOut, 없으면 acad-ts 폴백). ZWCAD 변환은 세트당 숨은 인스턴스 하나를 **전용 단일 스레드 executor**에서 열어 파일을 차례로 `convert_dwg_to_dxf(originals 사본, cache/dxf/<sha>.zwcad.dxf)`; 결과 DXF를 기존 `build_working_dxf_step`에 넣어 정본을 만든다. 실패(`ZwcadError`)하면 그 파일은 `builtin`으로 재시도하고 `converter_meta.fallback_reason`을 남긴다.
   - **같은 변환기 규칙(1차):** 한 파일이 `builtin`으로 떨어지면 상대 세트의 같은 파일 이름(정규화: 소문자·확장자 제거)도 `builtin`으로 변환한다(이미 ZWCAD로 끝났으면 다시 변환). 최종 짝 단위 판정은 R1-04가 한다.
   - 정본 생성 후 `font_names`(STYLE 테이블 font/bigfont 이름, 중복 제거·정렬)를 행에 저장.
   - 진행률: `ProgressReporter(progress, message, stage="convert", extra={"role","index","total","file","converter"})`. 메시지는 짧은 영문 코드(`convert 3/37 before A-101.dwg`), 한국어 표시는 UI 몫.
3. **표본 교차검증:** 두 변환기가 모두 가능한 PC(ZWCAD 가능 + (WS 데스크톱 연결 또는 acad-ts 브리지 존재))에서만, 세트당 `ingest.crosscheck_sample`개 파일(정렬 순 앞에서부터, 두 세트 합쳐 최대 2×N)을 builtin으로도 변환해 `validate/crosscheck`의 통계(엔티티 수·레이어·블록·텍스트 수)를 비교한다. 불일치는 `.halo/log/<compare_set_id>.log`에 한 줄씩(파일, 항목, 값1, 값2) 남기고 `compare_set.stats.crosscheck = {sampled, mismatched}`. 불가능하면 `{sampled: 0, mismatched: 0, skipped: "<이유>"}`.
4. 완료 시 `compare_set.status=ingested`, `stats`(파일 수·변환 성공·실패·제외·변환기별 수·`fonts_missing`·`crosscheck`). 실패 파일이 있어도 잡은 `done`이고 파일 행에 `FAILED`가 남는다(전부 실패면 `compare_set.status=failed`).
5. `GET /compare/sets` · `GET /compare/sets/{id}`(`CompareSetSummary`, 계약 §7; `frames`·`pairs` 카운트는 R1-04 전이므로 0) · `GET /compare/sets/{id}/files`.
6. `fonts_missing`: `font_names` 합집합 중 시스템 폰트 폴더(Windows `C:\Windows\Fonts`, `%LOCALAPPDATA%\Microsoft\Windows\Fonts`; macOS `/Library/Fonts`, `/System/Library/Fonts`, `~/Library/Fonts`)와 `<project_dir>/fonts`, `<bundle>/fonts`에 파일이 없는 이름(대소문자 무시, `.shx`·`.ttf` 확장자 보정).
7. 원본 불변: 모든 쓰기 전에 `assert_writable_path(path, allowed_roots=[bundle.root])`. 테스트가 소스 폴더의 파일 해시와 mtime이 그대로임을 확인한다.

## Defaults for ambiguity
- 폴더 안 하위 폴더는 **재귀하지 않는다**(1단계만). XR 폴더는 검색 경로로만 자동 추가(`<set_dir>/XR`, `<set_dir>/../XR`이 있으면 `search_paths`에).
- 같은 파일 이름이 대소문자만 다르면 같은 파일로 본다.
- 전·후 폴더가 같으면 허용한다(도곽 수 확인 용도). 이때 후 세트는 sha 캐시로 즉시 끝난다.
- acad-ts 폴백은 기존 설정(`Settings.converter_fallback`·`acad_bridge_bin`)을 그대로 따른다. 개발 환경(mac)에서 DWG를 넣으면 WS 데스크톱이 없을 때 acad-ts로 간다.
- `run_date`는 검증만 하고 이 태스크에서는 쓰지 않는다(R1-06·R1-09가 쓴다).
