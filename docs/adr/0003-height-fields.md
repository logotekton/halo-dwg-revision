# ADR-0003 높이 4필드 분리와 비교 금지 규칙

상태: 승인 (2026-09-02)

## 맥락
사용자(현업) 교정: 입면도에 표기된 레벨 치수는 **구조 레벨 기준 한 층의 높이**이고, 층고표는 **내부 건축 마감의 높이, 즉 천장고(ceiling height)** 다. 둘은 무조건 다르다. 이를 같다고 비교하는 검증은 항상 경보를 내는 무의미한 검사가 된다.

## 결정
높이를 네 개의 별도 필드로 저장하고 출처를 기록한다.

| 필드 | 뜻 | 출처 | 사용 |
|---|---|---|---|
| `SL` | 구조 레벨(슬래브 구조체 상단) | 입면도, 단면도, 구조 평면도 | 구조체 솔리드 높이, 외벽 마감 면 높이 |
| `FL` | 마감 바닥 레벨 | 건축 평면도, 단면도 | 바닥 마감 두께 |
| `FLOOR_HEIGHT` | 층고 = 인접 SL 차이 | 입면 레벨 차이 | 기둥·벽 구조체, 외벽 면 |
| `CH` | 천장고 = 마감 바닥에서 천장 마감까지 | 층고표, 마감표 비고, 천장평면도 | 실내 벽 마감 높이 |

검증 규칙:
- 같은 기준끼리만 등호 검사: 입면 SL ↔ 단면 SL ↔ 구조평면 SL (허용 5mm). 어긋나면 도면 오류 경보.
- 다른 기준 사이는 부등식만: `CH + 슬래브 두께 + 바닥 마감 두께 < FLOOR_HEIGHT`. 위반 시 값 오독 경보.
- **`CH`를 `SL`/`FL`/`FLOOR_HEIGHT`와 등호 비교하는 코드는 금지.** 스키마 검증기와 단위 테스트가 이를 거부한다.
- 층고표에 층고와 천장고가 나란히 있으면 열 이름과 값 크기 관계(천장고 < 층고)로 매핑을 검증한다.
- 천장고가 없으면 층고에서 슬래브·천장 속 공간을 빼는 대체 규칙을 쓰되 결과는 항상 저신뢰로 분류한다.

## 보충 2026-09-03 — 천장고끼리의 등호 검사
사용자 판정: **천장평면도에 CH가 표기된 경우에만** 층고표 CH와 천장평면도 CH를 등호(허용오차)로 검사한다. 천장평면도에 CH 표기가 없으면 검사를 생략한다(경보 아님). 스키마 규칙: `consistency-check`에서 `CH↔CH`의 `EQ`는 `left_source`/`right_source` 중 하나가 `CEILING_PLAN`일 때만 허용하고, 실행 시 해당 관측(`level_observation.kind=CH, source=CEILING_PLAN`)이 없으면 결과를 `SKIPPED`로 낸다. `level_source` enum에 `CEILING_PLAN`을 추가한다(W3-08 스키마 항목).
